# 時代小説・剣豪小説のための設定と書きかた

> このファイルは、流派・武芸の設定、立ち合いの描写、筋立ての型、刀剣、武家と市井の作法を扱います。
> 設定の保存先は `.novel/wuxia/`（`sects.md` / `martial-arts.md` / `weapons.md`）です。
> ディレクトリ名 `wuxia` は上流プラグインからの互換のために残しているもので、中身は日本の時代小説向けです。

## 一、武芸の設定

### 1.1 段位と腕前

日本の武芸は「段位の数字」ではなく「免許の段階」で表されます。流派ごとに呼び方は変わりますが、骨組みはおおむね次の形です。

| 段 | 呼び方の例 | できること | 上がる条件 | 代償・制約 |
|---|---|---|---|---|
| 初伝 | 切紙・入門 | 型をひととおり覚えた。素人には勝てる | 入門して一、二年の稽古 | 型どおりにしか動けない。崩されると立て直せない |
| 中伝 | 目録 | 間合いを読める。打ち合いが成立する | 三年から五年。立ち合いの経験 | 考えて動くので、不意を打たれると遅れる |
| 奥伝 | 免許 | 読まれていても通せる手を持つ | 十年前後。師の見立て | 体を痛める稽古を経ている。古傷が残る |
| 皆伝 | 印可・皆伝 | 相手の動きの起こりを見る。先を取れる | 二十年前後。流派に認められる | 教える責めを負う。自由に動けなくなる |
| 名人 | 位階にない | 抜かずに退ける。立ち合いそのものを避ける | 到達を目指すものではない | ここに至った者は、たいてい何かを失っている |

**設定を組むときの決めごと**
- どの流派にも「向かない相手」を置く。絶対に強い流派は作らない
- 段が上がるほど、失うものを増やす（古傷、立場、家族、時間）
- 腕前は数字で示さず、「相手の体勢がどう変わるか」で示す

### 1.2 分類

| 分類 | 特徴 | 名の付けかた | 書くときの語 |
|---|---|---|---|
| 太刀 | 間合いを取り、一手で決める | 流派名＋型名（例：陰流・落鴉） | 切先、鍔鳴り、振りかぶる、擦り上げる |
| 小太刀・脇差 | 懐に入って崩す | 動きから（例：逆手抜き） | 懐、逆手、絞る |
| 組討ち | 刀を抜けない場で使う | 技の形から（例：巻き落とし） | 崩し、投げ、締め |
| 槍・薙刀 | 間を制する。多人数に強い | 穂先の形から | 穂先、石突、払い、繰り出す |
| 弓 | 待って当てる | 射法から | 弦音、矢番え、引き絞る |
| 飛び道具・搦め手 | 不意を打つ。表では卑しまれる | 道具の名から | 気配、袖、懐 |

### 1.3 どの技にも書き入れること

- **名前**：流派の由来か、自然の景物から取る。意味の分かる名にする
- **口伝**：短い一句。長い説明にしない（例「打たせて勝つ」）
- **効き目**：どんな場面で通るか
- **弱み**：読まれたときにどう崩れるか
- **稽古の年月**：何年かかるか
- **代償**：体のどこを痛めるか、何を失うか

### 1.4 飛び道具と毒

- 飛び道具は力でなく、不意と間合いで効く
- 表の流派では卑しまれる。使えば立場を失う
- それでも使う理由を人物に持たせる（守るものがある、追われている、腕の差が絶望的）
- 毒を出すなら、効くまでの時間と解く手立てを決めておく

### 1.5 設定の原則 五つ

1. **代償を置く** — 強い技ほど失うものを大きくする
2. **相性を作る** — 全体の強弱はあっても、噛み合わせで覆る余地を残す
3. **年月をかけさせる** — 一夜で腕は上がらない。上がるなら理由を書く
4. **気質と結びつける** — 短気な者が「待つ剣」を修めるのは難しい
5. **出どころを書く** — その技が誰から誰へ渡ったかを決めておく

### 1.6 当たり前を忘れない

立ち合いの場面が嘘になるのは、たいてい次を書き落としたときです。

- 刀は折れる。曲がる。刃が欠ける
- 刃は脂で滑る。何人も斬れば切れなくなる
- 腕は疲れる。振り続けられるのは短い
- 血は多く出る。手が滑る
- 怪我は治るのに時間がかかる。その場で治らない
- 人を斬ったあと、人は平気ではいられない

## 二、勢力の組み立て

### 2.1 勢力の種類

| 種類 | 特徴 | 例として置けるもの |
|---|---|---|
| **藩** | 政がからむ。家中に派閥がある | 家老の一派と若手の一派、国元と江戸詰 |
| **流派・道場** | 剣の理と面目をめぐって争う | 城下の本家と在方の分家、新興の町道場 |
| **幕府の機構** | 規則で動く。個別の事情を扱えない | 目付、町奉行所、火盗改 |
| **市井** | 武家の論理の外にある | 商家、職人、船宿、芝居小屋 |
| **表に出ない者** | 記録に残らない | 隠密、浪人の群れ、流れ者 |

### 2.2 どの勢力にも書き入れること

- **頭に立つ者**：名前、人物像、どういう決め方をするか
- **その下**：二人から五人。それぞれ立場が違う
- **序列**：門人 → 目録 → 免許 → 皆伝 → 師範 → 宗家（流派の場合）
- **掟**：三つから五つ（例：他流試合の禁、師への礼、刀を抜いてよい場面）
- **看板の技**：その勢力を象徴する一手。皆伝の者だけが使える
- **由来**：誰が開いたか、いつか、どう衰えたか栄えたか
- **信条**：何のために剣を使うのか

### 2.3 置きやすい五つの型

#### 型一：城下の本家
- **ありよう**：藩の剣術指南を務める。家柄の子弟が集まる
- **看板の技**：代々伝わる太刀筋
- **内側の対立**：型を守る側と、実戦に合わせたい側
- **よく起きること**：跡目争い、他流試合の申し込み、伝書の紛失

#### 型二：在方の道場
- **ありよう**：村や在郷の道場。身分を問わず入れる
- **看板の技**：土地の仕事から出た実用の技（舟、山、農具）
- **内側の対立**：城下に認められたい者と、認められなくてよい者
- **よく起きること**：城下からの見下し、腕のある門人の引き抜き

#### 型三：幕府の機構
- **ありよう**：規則で動く。悪意はないが、人を追い詰める
- **特徴**：個別の事情を「前例」として処理する
- **よく起きること**：形だけの詮議、前例を盾にした拒否、記録の改め

#### 型四：隠れた上手
- **ありよう**：一人か二人。剣を捨てたはずの者
- **特徴**：終盤に一度だけ立つ。立てば何かを失う
- **よく起きること**：偶然の出会い、無言の手ほどき、死に際の一言

#### 型五：市井
- **ありよう**：商家、職人、船宿。武家の価値と別の尺度で生きている
- **特徴**：武芸の論理を外から見て、問いを投げる
- **よく起きること**：世話になる、匿われる、金の話、商いの筋を通される

### 2.4 勢力どうしの関係

| 関係 | 中身 | 変わりうる形 |
|---|---|---|
| **縁** | 婚姻や師弟でつながっている | 利が食い違えば切れる |
| **確執** | 代々の恨みか、利の衝突 | 外から脅かされると一時的に組む |
| **面目の張り合い** | 表は穏やか、内で競っている | 公の場で破れる |
| **預かり** | 一方が他方に恩を負っている | 返し終われば関係が終わる |

## 三、立ち合いの書きかた

### 3.1 緩急

日本の剣戟の特徴は「斬り合う時間が短い」ことです。打ち合いを長引かせないでください。

#### 静（間合い）
- 長めの文で時間を伸ばす
- 相手の息づかい、足の位置、肩の高さ
- 場の細部（風、鳥、水音、人の気配）

> 　二人のあいだは三間ほどあった。風が竹を鳴らして、それがやむのを二人とも待っていた。相手の爪先が、わずかに内へ向いた。

#### 動（一合）
- 短文を主にする。動詞を連ねる。体言止めを混ぜる
- 技名を並べるなら中黒か読点で区切る

> 　踏み込んだ。払う。受けた刃が鳴って、火花が散る。二合、三合。四合めで刃が噛んだ。

#### 静（読み合い）
- 内面か回想を一瞬だけ差し込む。長く止めない

> 　刀を引いたとき、師の言葉が浮かんだ。おまえの剣は、勝とうとしすぎる。

#### 動（決着）
- 短く。画を止める

> 　動いたのは相手だった。退かず、前へ出た。切先が、相手の掌の風を抜けた。

#### 静（余韻）
- 場の描写と、残るもの

> 　竹林が静かになった。刃の血に、落ち葉が一枚、張りついている。

### 3.2 腕前の見せかた

**「腕が立つ」と書かない。相手と場の変化で示す。**

| 腕前 | 相手に起きること | 場に起きること |
|---|---|---|
| 初伝 | 型どおり受けられる | 何も変わらない |
| 中伝 | 受けるのに一歩下がる | 砂利が鳴る |
| 奥伝 | 受けた腕が痺れる | 刃が噛み、鍔が鳴る |
| 皆伝 | 抜く音が聞こえず、構えが変わっている | 周りの者が息を止める |
| 名人 | 向かい合った時点で退く | 誰も動けない |

### 3.3 得物による書き分け

| 得物 | 呼吸 | 使う語 | 向いた場 |
|---|---|---|---|
| **太刀** | 間合いを取り、一手で決める | 切先、鍔鳴り、擦り上げる、振りかぶる | 一対一、屋外 |
| **小太刀・脇差** | 懐に入る | 逆手、絞る、懐、ねじ込む | 屋内、不意の遭遇 |
| **槍・薙刀** | 間を制する | 穂先、石突、払い、繰り出す | 多人数、屋外 |
| **弓** | 待って当てる | 弦音、矢番え、引き絞る | 待ち伏せ、離れた相手 |
| **組討ち** | 密着して崩す | 崩し、投げ、締め、巻く | 刀を抜けない場 |
| **飛び道具** | 不意を打つ | 気配、袖、懐 | 暗がり、追われている側 |

### 3.4 腕の差を越える五つの筋

| 筋 | 働き | 前に置く仕込み |
|---|---|---|
| **読み勝つ** | 地形、作法、相手の癖を使う | 事前の観察、土地の知識 |
| **一手だけ上をいく** | まだ見せていない手。代償を払う | その手を得た経緯 |
| **外の力を借りる** | 地形、天候、助け手、道具 | その力が使える理由 |
| **限界を超える** | 終わったあとに相応の代価がある | 追い詰められてきた積み上げ |
| **その場で掴む** | 立ち合いのなかで理を掴む | それまでの稽古と問い |

### 3.5 多人数との立ち合い

1. **主従をつける**：主要な一人か二人を細かく書き、残りはまとめる
2. **画を切り替える**：短文で視点を移し、場の混乱を出す
3. **全部書かない**：要になる三手から五手だけを細かく書く
4. **場を壊す**：障子、床、立木が壊れる
5. **形勢の変化を書く**：攻守がどこで入れ替わったか

### 3.6 立ち合いのなかの情

斬り合いは技の見せ場ではなく、**人がぶつかる場**です。

- **回想を差し込む**：決めの一手の前に、師か亡き者の言葉を一瞬だけ
- **信条をぶつける**：どの手を選ぶかに、その人の価値が出る
- **情が変わる**：怒りから静けさへ、恐れから諦めへ
- **決着のあと**：沈黙、息、吐き気、手の震え

## 四、よく使われる筋立て

### 4.1 腕を得る筋

#### 入門
- **中心の対立**：才がない vs 熱意で押す／師が取らない vs 取らねばならぬ事情
- **ひねり方**：師と弟子がそれぞれ秘密を抱えている／学ぶのが禁じられた手である
- **置きかた**：入門の場面そのものを書かず、三年後から始めるのも手

#### 手ほどき
- **中心の対立**：教えることで師が何かを失う
- **ひねり方**：教えた手が、のちに師に向く／教える過程で弟子の出自が分かる

#### その場で掴む
- **中心の対立**：生死の際で理が見える
- **ひねり方**：掴んだ代わりに何かを損なう／掴んだあと人が変わってしまう

### 4.2 ぶつかる筋

#### 他流試合
- **中心の対立**：腕が足りないが勝たねばならない／面目がかかっている
- **ひねり方**：試合が仕掛けである／立会人が買収されている／負けるために出る

#### 御前試合・奉納試合
- **中心の対立**：表は技を競う場だが、裏で政が動いている
- **ひねり方**：見物の中に敵がいる／勝つと困る立場にある

#### 争奪
- **中心の対立**：一つしかないものをめぐって人が変わる
- **ひねり方**：求めていたものが偽物／得た者が追われる立場になる

#### 立場の衝突
- **中心の対立**：どちらにも理がある。どちらかが折れるしかない
- **ひねり方**：味方に内通者がいる／対立そのものが第三者の仕込み

### 4.3 裏切りの筋

#### 師との決裂
- **中心の対立**：師か弟子が、相手の知らない面を知る
- **ひねり方**：師は弟子を守るために黙っていた／弟子は操られていた

#### 同門の離反
- **中心の対立**：縁を結んだ者が、利か信条で離れる
- **ひねり方**：離れた側に事情がある／和解するが裂け目は残る

### 4.4 伝説の筋

#### 隠れた上手が出る
- **中心の対立**：関わるまいとした者が、関わらざるを得なくなる
- **ひねり方**：出る理由は旧い因縁の決着／出てみると時代に合わなくなっている

#### 絶望から拾い上げる
- **中心の対立**：底に落ちた者が、思わぬものを得る
- **ひねり方**：得たものに代償がある／得た力がその人を変えてしまう

#### 伝書をめぐる
- **中心の対立**：書かれたものが力になる
- **ひねり方**：伝書が偽物／読める体でないと使えない／修めると追われる

### 4.5 情の筋

#### 行き合う
- **中心の対立**：立場の違う二人が出会う
- **ひねり方**：相手が仇の子である／身分を隠して過ごしたあと知れる

#### 命を預ける
- **中心の対立**：極まった場で、敵が味方になる
- **ひねり方**：預けたあとで別の狙いが分かる／生死を共にして互いを理解する

#### 恩と仇
- **中心の対立**：恩を返す相手と仇を討つ相手が同じ人である
- **ひねり方**：恩を選べば家を裏切る／仇を選べば大切な者を失う

### 4.6 市井の筋

#### 人情
- **中心の対立**：小さな困り事が、人の縁をたどって大きなものに触れる
- **ひねり方**：助けた相手が追われている／金で済む話が済まなくなる

#### 暮らしと剣
- **中心の対立**：剣では食えない。食うために剣を使うか、捨てるか
- **ひねり方**：捨てたはずの剣が必要になる／剣で得た金が人を傷つける

## 五、刀剣

### 5.1 分類

#### 刀（打刀・太刀）
- 武家の身分の証でもある
- 向いた人物：藩士、浪人、道場の者
- 書くこと：刃長、反り、拵えの色、重さ、手に馴染むか
- 癖の例：よく斬れるが脂に弱い／重いが折れない／見栄えはするが実用に向かない

#### 脇差・短刀
- 常に帯びている。屋内で使える
- 向いた人物：町人も帯びられる。女も持つ
- 癖の例：間合いが短く、入らなければ使えない

#### 槍・薙刀
- 家に備える武具。多人数に強い
- 向いた人物：足軽、寺社の者、屋敷を守る者
- 癖の例：屋内では使えない。長さが邪魔になる

#### 弓
- 離れた相手に届く。待つ道具
- 向いた人物：武家の素養として習う者、狩人
- 癖の例：雨で弦が緩む。射てから次までが遅い

#### 飛び道具・搦め手
- 不意を打つ。表では卑しまれる
- 向いた人物：隠密、追われている者、腕の差が絶望的な者
- 癖の例：一度使えば次は警戒される

### 5.2 一本ごとに書き入れること

- **名前**：由来の分かる名にする
- **来歴**：誰が鍛え、誰から誰へ渡ったか
- **見た目と手ざわり**：刃長、反り、拵え、重さ
- **持ち主**：いまと、これまで
- **癖**：よいところと、困るところ

### 5.3 刀は道具である

名刀を万能にしないでください。刀はよく斬れるだけで、持ち主を強くはしません。
強いのは人であって、刀は人を少し助けるだけです。この線を守ると、立ち合いが締まります。

## 六、作法と呼び方

### 6.1 武家の作法

| 作法 | 中身 | 破ったときに起きること |
|---|---|---|
| **名乗り** | 立ち合う前に名と流派を告げる | 告げずに斬れば、卑しい者と見られる |
| **他流試合の扱い** | 流派によって禁じられている | 禁を破れば流派を離れることになる |
| **仇討ちの筋** | 届を出し、立会人を立てる | 筋を通さなければ、ただの殺しになる |
| **刀を抜いてよい場面** | 屋内、城内、神域では抜けない | 抜けば所を汚したことになる |
| **預かりと返し** | 恩を受けたら返す | 返さなければ、人としての信を失う |

### 6.2 呼び方

| 呼び方 | 使う相手 | 使う側 |
|---|---|---|
| **殿・様** | 主君、上の立場の者 | 家臣、下の者 |
| **先生** | 師、医者、学のある者 | 門人、患者 |
| **お手前・貴殿** | 対等か、名を知らない相手 | 武家の者 |
| **某・拙者** | 自分（へりくだる） | 武家の者 |
| **御師範・宗家** | 流派の頭 | 門人 |
| **兄弟子・弟弟子** | 同門 | 同門 |
| **旦那・親方** | 商家や職人の頭 | 店の者、弟子 |
