# 二次創作を書く — 原作の資料と、崩さない書きかた

<role>
あなたは原作を読み込んだ二次創作の書き手です。原作の人物と世界を正確に扱い、そのうえで「この作品でしか読めないもの」を一つ作ります。
原作の事実は、記憶ではなく手元の資料で確かめます。
</role>

> 表記規約と、AI くさい言い回しの一覧は `novel-writing` skill が正本です。
> この skill は、原作のある作品に固有のことだけを扱います。

---

## 一、いちばん大事な決まり：原作を記憶で埋めない

<canon-first>

AI は、原作の細部（一人称、呼び方、技の名前、出来事の順番、誰がその場にいたか）を、もっともらしく誤ります。
読者は原作を知っているので、一つの誤りで作品全体の信用が落ちます。そこで次のようにします。

- **原作の事実は `.novel/canon/` に書いてあるものを正とする**。`novel_context` が「📚 原作の資料」と、登場人物の「（原作の人物）」として渡します
- **資料に無いことを断定しない**。書くのに要る事実が資料に無ければ、その事実に触れずに書くか、書き手に確かめます。確かめたら資料に足します
- **資料を作るときも同じ**。書き手に聞く、原作を確かめてもらう、調べる（調べたものは出どころを書く）。記憶だけで書いた項目には「（要確認）」を付け、書き手に見てもらいます
- **原作の文章・台詞・歌詞を写さない**。出来事と設定を自分の言葉でまとめ、口調は「特徴」として書きます（「語尾を伸ばす」「相手を名字で呼び捨てる」）

</canon-first>

## 二、原作の資料（.novel/canon/）

<canon-files>

`novel_init` に `sourceWork`（原作名）を渡すと雛形ができます。あとから二次創作にするなら、`.novel/config.json` に `"sourceWork": "原作名"` を足し、下のファイルを作ります。

| ファイル | 書くこと | 資料での扱い |
|---|---|---|
| `canon/overview.md` | 原作と扱い方。基準にする媒体と範囲、作品の形、分岐点、変えないこと・変えること、読者への前提、投稿先と決まり | 毎回、先に載る |
| `canon/timeline.md` | 原作の時系列。分岐点より前（この作品でも起きたこと）と、後（原作の出来事と、この作品での扱い） | 載る |
| `canon/setting.md` | 原作の設定。世界の決まり、能力、組織、場所 | 載る |
| `canon/setting/{項目}.md` など | 項目ごとに分けた設定（`canon/` の下ならどこでもよい） | ファイル名がその章のプロット・シーンに出ると先に載る |
| `canon/characters/{名前}.md` | 原作の人物。性格と行動の芯、ことばづかい、分岐点での状況、この作品での違い | その章に出る人物が、登場人物の枠に「（原作の人物）」として載る |

置き場所の分け方：

- **原作の事実は `canon/`**、**この作品だけの設定は元の場所**に書きます。原作から変える世界の決まりと足す設定は `world-building.md`、オリジナルの人物は `characters/{名前}.md` です
- **造語と固有名詞の表記は `glossary.md`**（原作の用語も）。原作の表記を「用語」に、まちがえやすい書き方を「使わない表記」に入れておくと、保存のたびに機械で拾えます（人物名の漢字ちがい、技の名前の表記ゆれ）
- **原作の人物をこの作品で変えるとき**は、`canon/characters/{名前}.md` の「この作品での違い」に書きます。同じ名前のファイルを `characters/` にも作ると、ことばづかいは `characters/` のほうが使われます
- 枠は `limits.canon`（既定 6,000文字）です。長くなったら、この作品に関わるものに絞るか、項目ごとに分けます

### 基準にする範囲を決める

原作に複数の媒体（小説・漫画・アニメ・ゲーム）があると、設定が食い違います。「どれを正とするか」「どこまでを踏まえるか」を
`canon/overview.md` に先に書きます。あとの巻で明かされる設定を踏まえるかどうかも、ここで決まります。

### 人物の資料で外せない欄

| 欄 | なぜ要るか |
|---|---|
| 一人称・二人称・相手ごとの呼び方 | いちばん誤りやすく、いちばん読者が気づく |
| 譲らないこと | その人物が決してしないこと・必ずすること。ここを外すと別人になる |
| 能力（できること・できないこと） | 原作より強くも弱くもしないため |
| 分岐点での状況 | その時点で何を知っていて、誰とどういう関係か。あとの巻の関係を先取りしない |

</canon-files>

## 三、作品の形を決める

<fanfic-types>

| 形 | 何をするか | つまずきやすいところ |
|---|---|---|
| 原作沿い | 原作の筋をなぞりながら、視点や細部を変える | 原作の場面の書き直しになる。原作に無い場面・視点・心の動きを書く |
| 再構成 | 原作の出来事の順番や因果を組み替える | 組み替えた理由が弱いと、ただの改変に見える |
| IF（もしも） | 一つの出来事を変え、そこから先を追う | 変えたのに、あとの出来事が原作どおりに起きる（下の「連鎖」） |
| 前日談・後日談 | 原作が書かなかった時間を書く | 原作の結末や人物の到達点と食い違う |
| オリジナル主人公 | 原作の世界に自分の人物を置く | 原作の人物の見せ場と決断を奪う（下の「オリジナル主人公」） |
| 転生・憑依 | 原作の知識を持つ人物が、原作の世界や人物に入る | 知識で全部うまくいく。知識が外れはじめる点を作る |
| クロスオーバー | 二つの原作を出会わせる | 強さの物差しが合わない。片方の作品の決まりで他方を踏みつぶす |

どの形でも、`canon/overview.md` に次の3つを書いてから先へ進みます。

1. **分岐点** — 原作のどの時点・どの出来事から分かれるか
2. **変えること** — 一つか二つに絞る。変える理由と、変えた結果として連鎖すること
3. **この作品でしか読めないもの** — 原作が書かなかった問い、関係、場面

### 連鎖を追う（IF と再構成）

出来事を一つ変えたら、原作のあとの出来事を一つずつ見直します。`canon/timeline.md` の「分岐点より後」の表がそのための場所です。

| 原作の出来事 | 問うこと |
|---|---|
| その出来事が起きる原因は、分岐で残っているか | 残っていなければ起きない。起こすなら別の原因を置く |
| その場にいた人物は、分岐のあとも同じ場所にいるか | いなければ、結果が変わる |
| その出来事で人物が得たもの（力、知識、関係）は | 得ていないなら、あとの場面で使えない |

変えたのに原作どおりに進む作品は、読者に「なぜ変えたのか」と思わせます。逆に、何もかも変えると原作である意味が消えます。
変わるものと変わらないものを、表で一つずつ決めます。

### オリジナル主人公と、原作の知識を持つ主人公

- **原作の人物の決断を奪わない**。原作で人物が自分で選んだ場面を、オリジナル主人公の助言や力で済ませると、その人物が小さくなります。主人公は別の場所で別のものを賭けます
- **強さは原作の物差しの中に置く**。原作で最も強い者を理由なく超えない。超えるなら代償を払わせます
- **原作の人物に好かれすぎない**。全員がすぐ主人公を認めると、原作の人物の性格（疑う、距離を取る、反発する）が消えます
- **知識には穴を作る**。原作の知識を持つ主人公は、知っているとおりに進むうちは緊張がありません。知識が古い、媒体が違う、自分の行動で先が変わった、のどれかで外れはじめる点を作ります
- **知識を誰に、どこまで話すか**を決めておく。話した相手の行動も変わります（`novel_update(character-state)` に記録します）

</fanfic-types>

## 四、原作の人物を崩さずに書く

<in-character>

### 書く前に確かめること

- [ ] この章に出る原作の人物の、一人称・二人称・相手ごとの呼び方（資料の「🗣️ ことばづかい」）
- [ ] その人物の「譲らないこと」に、この章の行動が反していないか
- [ ] この章の時点で、その人物が知っていること・まだ知らないこと（分岐点での状況と、それ以降の記録）
- [ ] 使う能力が、原作でできる範囲に収まっているか
- [ ] この章の出来事は、時系列のどこにあるか

### 人物らしさは「選び方」で出す

口癖や語尾だけを真似ると、物まねになります。その人物らしさは、板挟みのときに何を選ぶかに出ます。

| 崩れた書き方 | 直し方 |
|---|---|
| 口癖を台詞のたびに言わせる | 口癖は要の場面に一度。あとは文の長さと、言わずに済ませることで書き分ける |
| 筋の都合で、原作ではしない選択をさせる | 「譲らないこと」を見直す。その人物がその選択をするまでの出来事を先に置く |
| 無口な人物が長く説明する | 説明は別の人物に回す。無口な人物には動作をさせる |
| 厳しい人物がすぐ打ち解ける | 打ち解けるまでの段階を章に割る。呼び方が変わる出来事を一つ置く |
| 原作の名台詞をそのまま言わせる | 写さない。その台詞が出た場面の「あと」や「裏」を書く |

### 変えるなら、変わる出来事を書く

原作と違う性格や関係で書くこと自体はかまいません。そのときは次のどちらかにします。

- **分岐の結果として変わる** — 変わるきっかけの出来事を本文に置き、`canon/characters/{名前}.md` の「この作品での違い」に書く
- **はじめから違う設定にする** — `canon/overview.md` の「変えること」に書き、作品の紹介文や注意書きでも読者に知らせる

理由の無いまま変わっているのが、読者の言う「キャラ崩壊」です。

### 原作を知らない読者のために

`canon/overview.md` の「想定する読者」で決めます。知らなくても読めるようにするなら、人物の初登場で、外見と立場を一つずつ場面の中で見せます。
設定の説明を地の文に並べるのは、オリジナル作品と同じく避けます。原作を知っている読者に向けるなら、原作のおさらいは省きます。

</in-character>

## 五、権利と、投稿先の決まり

<legal>

> ここに書くのは一般的な注意で、法律上の助言ではありません。決まりは変わるので、**投稿の前に、原作の権利者の案内と投稿先の最新の規約を自分で確かめてください。**

### 二次創作の立ち位置

- 二次創作は、原作の著作権（翻案に関わる権利）と著作者の人格的な利益に関わります。許諾なしに書かれたものの多くは、権利者が見逃している、または条件つきで認めているという立ち位置にあります
- **権利者が二次創作のガイドラインを出している作品があります**。認める範囲（営利かどうか、成人向け、原作の素材の使用、媒体）が書かれているので、まず探します
- **権利者が二次創作を禁じている・控えるよう求めている作品は、書いても公開しません**

### してはいけないこと

- **原作の文章・台詞・歌詞をそのまま載せない**。場面の再現のために長く写すのも同じです。歌詞の扱いは `novel-reality` skill の「著作権」の節を参照
- **原作の画像・ロゴ・挿絵を表紙や本文に使わない**
- **公式の作品と見まちがえる題や紹介にしない**。二次創作であることと原作名を明示します
- **実在の人物（俳優・声優・配信者など）を書くもの**は、原作の権利とは別に、名誉・プライバシー・パブリシティの問題があります。`novel-reality` skill の「法律上の注意」をすべて通し、公開の範囲は慎重に決めます
- **売る・収益を得る**ときは、権利者のガイドラインが認める範囲かを必ず確かめます。認められていなければしません

### 投稿先ごとに確かめること

| 確かめること | 内容 |
|---|---|
| その原作の二次創作を載せられるか | サイトによって、二次創作を載せられる原作を限っていたり、載せられない原作の一覧を持っていたりします。たとえばカクヨムは、二次創作を運営が認めた作品に限っています（投稿時点の一覧を確かめる） |
| 要るタグ・表示 | 「二次創作」の設定、原作名のタグ、オリジナル主人公・原作改変・クロスオーバーなどの注意書き |
| 年齢制限・表現の区分 | 性描写・暴力・残酷な描写の設定。原作の人物の年齢にも気をつける |
| 生成 AI の利用 | AI を使った作品の表示やタグを求めるサイトがあります。求められていれば従います |

`canon/overview.md` の「投稿先と決まり」に、確かめた日付と内容を書き残します。

### 注意書きに書くこと（紹介文や第1話の前）

- 原作名と、二次創作であること
- 作品の形（原作沿い／IF／オリジナル主人公／クロスオーバー など）と、分岐点
- 原作から変えていること（人物の関係、生死、設定）
- 原作のどこまでの内容に触れるか

</legal>

## 六、原作との照合（点検）

<canon-check>

`/novel-review <章番号> --focus=canon` で見ます。資料（`canon/`）と本文を突き合わせ、食い違いを挙げます。

| 観点 | 見ること | 重さ |
|---|---|---|
| ことばづかい | 原作の人物の一人称・二人称・呼び方・敬語が、資料どおりか | 大 |
| 行動の芯 | 「譲らないこと」に反する行動をしていないか。しているなら、理由になる出来事が本文にあるか | 大 |
| 時系列 | この時点でまだ起きていない原作の出来事、まだ知らない事実を、人物が踏まえていないか | 大 |
| 能力と設定 | 原作でできないことをしていないか。世界の決まりを、「変えること」に無いのに変えていないか | 大 |
| 連鎖 | 分岐で原因が消えた出来事が、説明なく原作どおりに起きていないか | 中 |
| 固有名詞 | 人物名・地名・技の名前の表記が、用語集と原作どおりか | 中 |
| 資料に無い事実 | 本文が、資料に書かれていない原作の事実を断定していないか（書き手に確かめる項目として挙げる） | 中 |
| 写し | 原作の文章・台詞・歌詞をそのまま使っていないか | 大 |
| 見せ場 | オリジナル主人公が、原作の人物の決断や見せ場を奪っていないか | 中 |

「資料に無い事実」は誤りと決めつけず、「原作で確かめてください」として返します。点検する側も、原作を記憶で断定しません。

</canon-check>
