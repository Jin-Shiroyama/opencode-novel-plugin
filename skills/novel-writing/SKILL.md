## 反 AI 套话规则（必须遵守）

<anti-ai-patterns>

### 绝对禁止的词汇和句式

| 禁止 | 原因 | 替代方案 |
|------|------|---------|
| "总之"、"综上所述"、"总的来说" | 总结性过渡，暴露AI | 直接切换场景或用动作过渡 |
| "不禁" + 动作 | AI高频套话 | 描写具体生理反应 |
| "一股XX涌上心头" | 模板化情感描写 | 用行为和感官细节展现 |
| "心中暗道"、"心道" | 过度使用 | 直接写内心想法，不加标签 |
| "宛如"、"犹如" + 比喻 | AI偏好比喻句 | 克制使用，每千字不超过1个比喻 |
| "只见" + 描写 | 评书风格 | 直接描写所见 |
| 连续多个感叹号！！！ | 不专业 | 最多一个 |
| "此刻"、"这一刻" | AI时间标记 | 用场景细节暗示时间 |
| "仿佛整个世界都..." | 夸大其词 | 保持具体和克制 |
| "眼神中闪过一丝XX" | AI模板化眼神描写 | 用更具体的眼部动作 |

### 禁止的写作模式

1. **大段内心独白替代行为描写** — 用 Show, Don't Tell
2. **角色情绪过于理性清晰** — 真人的情绪是混乱的、矛盾的
3. **对话过于书面化** — 真人说话有语气词、省略、打断
4. **场景描写过于抽象** — 要有五感细节
5. **每段都有比喻** — 比喻是调料，不是主菜
6. **刻意营造悬念感** — 悬念来自情节，不是修辞

### 必须做到

1. **场景描写用五感** — 视觉为基础，关键时刻叠加听觉/嗅觉/触觉
2. **对话自然化** — 加入语气词（"嗯"、"啊"、"那个"），允许说话不完整
3. **角色有辨识度** — 每个角色有口头禅和说话习惯
4. **紧张用短句** — 战斗/紧张场景用短促的句子
5. **放松用长句** — 抒情/描写场景可以用较长的句子
6. **情感通过行为展现** — 不说"他很难过"，而是描写他的动作

</anti-ai-patterns>

## 写作示范

<writing-examples>

### 示范 1：情感描写

❌ **AI风格（生硬、套话）：**
> 他不禁感到一股悲伤涌上心头，此刻的他仿佛整个世界都崩塌了。眼中闪过一丝哀伤，宛如被抽去了所有力气。

✅ **人话风格（自然、具体）：**
> 他蹲下来，把碎了的碗一片一片捡起来，手被割了一道口子也没停下。血滴在白色的碎瓷上，像开了几朵小红花。

**差别在哪？** 第二段没提一个"悲"字，但你能感受到他的状态——蹲在地上一片片捡碎碗，割了手不停，这就是 Show Don't Tell。

### 示范 2：对话描写

❌ **AI风格（书面化、人人说话都一样）：**
> "我不同意你的做法，这样做太过冒险了。"李长安严肃地说道。
> "但是这是唯一的办法，我们不能坐视不理。"白夜反驳道。

✅ **人话风格（口语化、有个性）：**
> "你疯了吧？"李长安瞪着白夜。
> "疯？我这叫胆大。"白夜不以为意，"再说了，你那叫坐以待毙，不叫稳重。"
> "那叫送死！"
> "送死也得看死得值不值。"

**差别在哪？** 第二段里两个人说话风格不同——李长安急躁直白，白夜毒舌傲慢。读者闭着眼都能分清谁在说话。

### 示范 3：场景描写

❌ **AI风格（抽象、全是形容词）：**
> 这是一片美丽而神秘的森林，阳光透过树叶洒下斑驳的光影，空气中弥漫着清新的气息，令人心旷神怡。

✅ **人话风格（五感、具体细节）：**
> 林子里暗，脚下的落叶踩上去咯吱响。有股子腐叶混着松脂的味道，不难闻，但有点闷。阳光从头顶的缝隙漏下来，在地上画了一个个亮圈，有虫子绕着光圈飞。

**差别在哪？** 第二段有听觉（咯吱响）、嗅觉（腐叶混松脂）、视觉（亮圈、虫子），还带点触感（闷）。读着像你真的站在那片林子里。

</writing-examples>

## 章节开头模板

<chapter-openings>

> 不知道怎么开篇？从下面5种开头方式中选一个，直接套用。

### 1. 动作开头 — 直接进入冲突

```
[角色]正在[做一件具体的事]，突然[发生了意外]。
```

**示例：**
> 李长安的笔尖在纸上停住了。不是因为他写不下去——是桌子在抖。先是微微的颤，然后整面墙开始簌簌掉灰。

**适用场景**：需要立刻抓住读者注意力的章节（打斗前、转折点）

### 2. 对话开头 — 用对话引出场景

```
"[一句有悬念或冲突的话。]"[角色A][动作]。
"[回应。]"[角色B][动作/表情]。
```

**示例：**
> "你欠我的三条命，打算什么时候还？"
> 白夜靠在门框上，把玩着手里那根草茎，像是随口问今天天气怎么样。

**适用场景**：两人之间有张力、需要展现关系的章节

### 3. 环境开头 — 用五感描写带入

```
[声音/气味/温度等感官]描写。[角色的感受或动作]。
```

**示例：**
> 雨下了三天，还没停的意思。巷子里的积水没过脚踝，混着泥和不知道什么东西，每走一步都能闻到一股腥味。李长安把书稿举过头顶，踮着脚往前趟。

**适用场景**：需要营造氛围、过渡到新地点的章节

### 4. 回忆开头 — 从过去切入

```
[角色]想起[过去的某个画面/事件]。[和现在的连接]。
```

**示例：**
> 柳教授第一次见李长安的时候，他只有七岁，蹲在学堂门口偷听讲课。现在这个蹲在门口的小子站在了他面前，手里握着一把不该出现的剑。

**适用场景**：需要揭示角色背景、连接过去和现在的章节

### 5. 悬念开头 — 先抛出问题

```
[一个反常的现象/一句话/一个结果]，[角色]不知道的是[更重要的真相]。
```

**示例：**
> 告示贴出去不到半天就被人撕了。李长安不知道的是，撕告示的人不是讨厌他写的字——是认出了他用的墨里有剑气的残余。

**适用场景**：需要制造好奇心、吊读者胃口的章节

</chapter-openings>

## 新手常见问题

<beginner-faq>

**Q: 不知道怎么开始写？**
→ 先写你最兴奋的那个场景。不用从第一章写，写你最想写的那段。写完再往前补。

**Q: 对话写不自然？**
→ 试着大声念出来。不顺畅的地方、读着别扭的地方，就是需要改的。真人是这么说话的吗？

**Q: 场景描写很空洞？**
→ 想象你站在那个地方：你看到了什么？听到了什么？闻到了什么？皮肤上感觉到了什么？把你感受到的写下来。

**Q: 写着写着偏离大纲了？**
→ 偏了一点没关系。但如果偏太多，停下来看看：这个新方向是不是比大纲更好？如果是，就调整大纲。如果不是，删掉重来。

**Q: 每章写多少字合适？**
→ 3000-5000字是一个舒适的区间。太短了场景展开不了，太长了读者容易疲劳。重要章节可以写到6000字。

**Q: 怎么避免写着写着角色就"变味"了？**
→ 每个角色给他一句口头禅和一个说话习惯。写的时候默念"这个人会怎么说这话"。如果不确定，回去看角色档案。

**Q: 章节结尾总是写不好？**
→ 章节结尾三招：① 悬念（"他打开门，愣住了"）② 转折（突然来了个意想不到的人）③ 反问（角色陷入两难）。选一个，别让章节平平淡淡地结束。

**Q: 总觉得写出来的东西像AI生成的？**
→ 检查你的文字里有没有这些词："不禁"、"一股XX涌上心头"、"此刻"、"仿佛整个世界"。有的话删掉重写，用动作和细节代替。参见上面的"写作示范"。

</beginner-faq>

## 感官描写指南

<sensory-guide>

### 五感选择原则

| 场景类型 | 主要感官 | 辅助感官 |
|---------|---------|---------|
| 战斗/追逐 | 视觉 + 触觉 | 听觉 |
| 日常对话 | 听觉 | 视觉 |
| 美食/宴会 | 味觉 + 嗅觉 | 视觉 |
| 恐怖/悬疑 | 听觉 + 触觉 | 嗅觉 |
| 回忆/思念 | 视觉 + 触觉 | 嗅觉（最触发记忆） |
| 自然环境 | 视觉 + 嗅觉 | 听觉 |

### 关键时刻多感官叠加

在以下场景至少使用3种感官：
- 角色第一次进入新场景
- 高潮/转折时刻
- 角色情绪极度激烈的时刻

### 平常场景克制描写

日常过渡场景只需1-2种感官，避免描写过度疲劳读者。

</sensory-guide>

## 场景类型写作指南

<scene-types>

### 主动场景（Goal → Conflict → Disaster）

```
目标: 角色想要什么（明确、具体）
  ↓
冲突: 遇到什么阻碍（来自对手、环境、自身）
  ↓
挫折: 结果比预期更糟（不是简单的失败，而是让情况更复杂）
```

**写作要点**:
- 目标在场景前1/3内明确
- 冲突要有来有回，不是一面倒
- 挫折要带来新问题，推动情节

### 被动场景（Reaction → Dilemma → Decision）

```
反应: 对上一场景的情绪反应（不是理性分析）
  ↓
困境: 面临艰难选择（两个选项都有代价）
  ↓
决定: 做出选择（推动情节进入下一个主动场景）
```

**写作要点**:
- 反应是感性的，可以混乱、矛盾
- 困境要真正困难，不能有显然正确的选择
- 决定要有代价，为后续埋下伏笔

### 交替节奏

```
主动(紧张) → 被动(反思) → 主动(更紧张) → 被动(更深层的反思) → ...
```

每2-3个主动场景后插入一个被动场景，让读者和角色都有喘息空间。

</scene-types>

## 衔接与续写

<continuation>

### 第2章及以后的特殊规则

1. **开头不重复** — 检查本章开篇是否与上一章末尾内容重复
2. **自然衔接** — 从上一个场景的结尾自然过渡
3. **推进事件** — 确保本章推进到大纲中规划的新事件
4. **参考上一章末尾** — `novel_context` 自动提供上一章末尾500字

### 长篇一致性保持

- 每5章进行一次一致性检查
- 角色语言风格保持一致（口头禅、语气词）
- 时间线不要矛盾（注意日夜更替、季节变化）
- 物品/能力不能凭空出现或消失
