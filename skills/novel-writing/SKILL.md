## 章を書く手順

<writing-flow>

### 手順1: 資料をそろえる

```
novel_context(chapterNumber: N, includePrompts: true)
```

返ってくるもの:
- P0: この章のプロット（必ず従う）、この章のシーンと `_Prompt`
- P1: 登場人物（この章に出る人物は個別の設定も付く）、その現在の状態、前章とのつなぎ
- P2: これまでのあらすじ、伏線の確認
- 執筆プロンプト

特定のシーンだけを書くときは `sceneId` を渡すと、そのシーンに印が付きます。

```
novel_context(chapterNumber: N, sceneId: "2.1", includePrompts: true)
```

### 手順2: 資料を読む

書き出す前に確かめます。
- [ ] この章で起きる出来事は何か
- [ ] この章のシーンは何に分かれているか。各シーンの `_Prompt` は何を求めているか
- [ ] この章で扱う伏線はあるか
- [ ] 登場人物はいまどういう状態か
- [ ] 前章はどの場面で終わったか（つなぎ目を作るため）
- [ ] この章の視点人物は誰か

### 手順3: 本文を書く

本文だけを出します。章タイトル、番号、注記は書きません。

### 手順4: 保存する

```
novel_save_chapter(chapterNumber: N, title: "章タイトル", content: "本文")
```

### 手順5: 記録を更新する

```
novel_update(action: "character-state", chapterNumber: N, content: '{"updates":[{"name":"人物名","changes":{"mentalState":"…"}}]}')
novel_update(action: "summary", chapterNumber: N, content: "この章だけのあらすじ")
novel_update(action: "foreshadow", chapterNumber: N, content: '{"items":[{"id":"F1","status":"resolved"}]}')
```

JSON の形はツールの説明にある例のとおりにします。形が違うと何も書き込まれず理由が返るので、直して渡し直します。
あらすじは章ごとの節で残るので、前の章の分を書き足す必要はありません。
最後に、シーン一覧でこの章で書いたシーンの状態を `[x]` に直します。

</writing-flow>

## 表記規約（必ず守る）

<style-rules>

### 会話

- 会話は `「」` で囲む。会話中の引用、作中の本や手紙は `『』`
- **会話文末に句点を打たない**
  - ○ `「行こう」`　× `「行こう。」`
  - 読点は打ってよい　○ `「いや、それは違う」`
- 三点リーダ・ダッシュで終わる会話も句点なし　○ `「それは……」`
- `「」` の中では改行しない
- 会話のあとに動作を続けるときは行を分ける
  ```
  「行こう」
  　森田は鞄を掴んで立ち上がった。
  ```

### 三点リーダとダッシュ

- 三点リーダは **`……`**（U+2026 を2つ重ねる）。単独の `…` や3つ重ねの `………` は使わない。伸ばすときも偶数個（`…………`）
- ダッシュは **`――`**（U+2015 を2つ重ねる）。単独の `―` は使わない。`—`（U+2014）や `ー`（長音符）で代用しない。伸ばすときも偶数個
- 三点リーダ・ダッシュの直後に全角スペースを入れない
- 半角ピリオド3つ `...` は使わない

### 感嘆符・疑問符

- 全角 **`！`** **`？`** を使う。半角 `!` `?` は使わない
- 重ねや組み合わせ（`！！` `！？` `？！`）は使ってよい。続けたものは1つの約物として扱う（直後の全角スペースも1つ）
- **直後に全角スペース1つを入れる**
  - ○ `　本当か？　彼は息を止めた。`
  - ○ `「待て！　行くな」`
- ただし次の場合はスペースを入れない
  - **閉じ括弧の直前**　○ `「待て！」`　× `「待て！　」`
  - **行末・段落末**
  - **約物が連続するとき**　○ `「どこだ！？」`

### 段落

- 段落頭は**全角スペース1字分の字下げ**
- `「` で始まる会話行は字下げしない
- 三点リーダ・ダッシュで始まる行も字下げしない
- 段落の途中で改行しない（1段落は論理的に1つのまとまり）

### 数字・英字

- 地の文の数量は**原則漢数字**（三日後、十七歳、二百円、一つ）
- 年号・型番・住所など算用数字が自然なものは半角で統一
- 同じ作品内で漢数字と算用数字を混在させない
- 日本語と英数字のあいだに半角スペースを入れない

### 書き出しの一例（規約を満たした形）

```
　放課後の職員室は、暖房を切ったあとの乾いた匂いがした。隣の席のパソコンがまだ唸っていて、誰かが帰りそこねていることだけが分かる。
「先生、あれ出しました」
　廊下の光を背にして立っているので、杉本の顔は影になっていた。森田は手元の名簿をもう一度見た。出した、という記録はどこにもない。
「いつ」
「先週の……たしか、水曜です」
　水曜。森田はその日の自分を思い出そうとして、思い出せなかった。
```

### 機械での点検

保存すると、`novel_save_chapter` の報告に表記の点検結果（件数と最初の数箇所）が出ます。
`novel_check(chapterNumber: N)` で全件を行と字の位置つきで見られます。❌（規約違反）は直して保存し直します。
⚠️（地の文の算用数字、日本語と英数字のあいだの半角スペース）は、意図したものなら残してかまいません。

機械で見ているのは、括弧の対応、会話文末の句点、三点リーダとダッシュ、それらのあとの空白、
半角の `!` `?`、感嘆符・疑問符のあとの全角スペース、段落頭の字下げ、全角の算用数字です。
漢数字と算用数字の使い分けが作品の中でそろっているかは、目で確かめます。

</style-rules>

## AI くさい言い回しを避ける（全一覧）

<anti-ai-patterns>

> この一覧は、日本語の AI 生成文に実際に現れる癖から起こしたものです。
> 中国語版の直訳ではありません。

### A. 語彙・慣用句（使わない）

| 使わない表現 | なぜ AI くさいか | 代わりにどう書くか |
|---|---|---|
| 思わず〜／〜せずにはいられなかった | 最頻出の AI 語。動作の自発性を説明で埋めている | 動作をそのまま書く →「口の端が上がった」 |
| 胸が熱くなった／胸の奥が締めつけられた／込み上げてきた | できあいの感情表現。誰が書いても同じ文になる | 身体の細部 →「鼻の奥が痛くなって、襟を直すふりで顔を伏せた」 |
| その瞬間／次の瞬間／この瞬間 | 時間を接着剤で貼る癖。場面の因果を省略する言い訳 | 動作の連続で時間を示す |
| まるで〜のようだった／〜かのように | 比喩の自動生成 | 比喩を削り、事物を直接書く（比喩は1,000文字に1つまで） |
| 世界が止まったかのように／世界から音が消えた | 誇張の定型 | 具体を一つ →「冷蔵庫の音だけが聞こえた」 |
| 目の奥に〜が揺れた／瞳に一瞬〜の色が浮かんだ | 眼の描写のテンプレート | 目の具体的な動き →「目を細めた」「視線を外した」 |
| 心の中で呟いた／胸の内で呟く | 独白にラベルを貼っている | ラベルを外し、地の文にそのまま置く |
| 言葉を失った／息を呑んだ／絶句した | 驚きのできあい表現。多用で無価値になる | 1章1回まで。あとは動作で |
| 静寂が支配した／沈黙が降りた／空気が張り詰めた | 空気描写の定型 | 聞こえるものを一つ書く |
| 要するに／つまり／結論として／言うまでもなく | 総括語。地の文に論文の癖が出る | 削る。場面を切り替える |
| 〜なのだった／〜であった（説明調の文末） | 語り手が読者に解説する姿勢 | 「〜た」「〜る」の素の文末へ |
| ドクンと心臓が跳ねた／ゴクリと喉を鳴らした／視界が涙で滲んだ | オノマトペ込みの完成品フレーズ | オノマトペを外して具体化 |
| 運命は彼を許さなかった／だが、それだけではなかった | 煽りのナレーター介入 | 削る。次の場面を出す |
| 〜を余儀なくされた／〜を禁じ得なかった | 硬い漢語調。心情や会話に合わない | 平たい言葉に |

### B. 文末とリズム

| 避けること | 理由 | 対処 |
|---|---|---|
| 同じ文末が3文以上続く（「〜た。〜た。〜た。」） | **AI 出力の最大の特徴**。日本語は文末の変化がリズムを作る | 「〜た／〜ている／体言止め／〜のだ」を混ぜる |
| 1文が80文字を超える | 読点で継ぎ足した訳文調 | 2〜3文に割る |
| 全段落が同じ長さ | 機械的に見える | 1行段落と長い段落を混ぜる |
| 情景→心情→台詞の順序が全段落で同じ | テンプレート運用 | 順序を崩す。台詞から入る段落を作る |
| 副詞に頼る（静かに／ゆっくりと／そっと／確かに） | 動詞が弱いのを副詞で補っている | 動詞を替える →「そっと置いた」→「音を立てずに置いた」 |

### C. 構文・視点

| 避けること | 理由 | 対処 |
|---|---|---|
| 固有名詞を毎文で繰り返す | 英語直訳。日本語は主語を省略する | 2文目以降は省く。「彼」も省けるなら省く |
| 体の部位を主語にする（彼の目が彼女を捉えた） | 英訳調 | 人を主語に →「彼女を見た」 |
| 視点人物に見えないものを書く（自分の表情、背後） | 三人称一元視点の崩れ | 視点人物が知覚できる範囲に限る |
| 説明台詞（「知っているだろう、この街は十年前の――」） | 設定の説明過多 | 対立や行き違いの中で断片的に出す |
| 1段落に設定説明が3文以上 | 同じ | 動作の合間に1文ずつ |

### D. 台詞

| 避けること | 理由 | 対処 |
|---|---|---|
| 全員が標準語・同じ語尾 | 名前を隠すと誰の発言か分からない | 1人につき語尾・口癖・文の長さを1つ決める |
| 過剰な役割語（〜だぜ／〜ですわ／〜じゃのう） | 記号的で古い | 語彙と文の長さで差をつける |
| 台詞が文法的に完全すぎる | 実際の会話は中断・省略・言い直しを含む | 「――いや、そうじゃなくて」を混ぜる |
| 「〜だな」と彼は言った。の反復 | 発話動詞が単調 | 動作で話し手を示す →「彼は湯呑みを置いた。「そうだな」」 |

### E. 約物（表記規約と重なる）

| 避けること | 対処 |
|---|---|
| `…` 単独、`………` 奇数個 | 必ず `……` |
| `―` 単独、`—`（U+2014）、`ー`（長音符）での代用 | 必ず `――`（U+2015 を2つ） |
| 半角 `!` `?` `...` | 全角 `！` `？`、`……` |
| `〜` の多用（語尾伸ばし） | 会話の癖づけ以外では使わない |

### やること（必須8項目）

1. 感情は身ぶりと場の描写で示す（「悲しい」と書かず、手の動きを書く）
2. 要の場面は五感を3種以上、日常の場面は1〜2種に抑える
3. 1シーン1視点人物に固定する（三人称一元視点）
4. 1人につき1つ、話し方の癖を持たせる
5. 緊迫は短文と体言止め、落ち着きは長文
6. 比喩は1,000文字に1つまで
7. 章末に引きを1つ置く
8. 同じ単語を1段落で2回使わない（意図した反復は除く）

</anti-ai-patterns>

## 書き比べ

<writing-examples>

### 例1：感情

❌ **AI くさい書き方**
> 　彼は思わず悲しみが込み上げてくるのを感じた。その瞬間、まるで世界のすべてが崩れ落ちたかのようだった。目の奥に哀しみの色が浮かび、全身の力が抜けていくのだった。

✅ **人が書いた文**
> 　彼はしゃがんで、割れた碗を一片ずつ拾った。指を切っても手を止めなかった。血が白い破片の上に落ちて、小さな花がいくつか咲いたように見えた。

**どこが違うか**：後者には「悲しい」という語が一つも出てきません。それでも状態が伝わります。しゃがんで一片ずつ拾う、手を切っても止めない。この二つで足ります。

### 例2：会話

❌ **AI くさい書き方**
> 　「私はあなたの方法に同意できません。それはあまりにも危険です」森田は厳しい表情で言った。
> 　「しかしこれが唯一の方法です。私たちは手をこまねいているわけにはいきません」杉本は反論した。

✅ **人が書いた文**
> 　「正気か」
> 　森田は杉本を見た。
> 　「正気です。度胸があるって言ってください」
> 　「度胸じゃない。無茶だ」
> 　「無茶でも、何もしないよりましです」
> 　「ましかどうかは、終わってからしか分からないだろう」

**どこが違うか**：後者では二人の話し方が分かれています。森田は短く切って断定し、杉本は丁寧語のまま押し返す。名前を隠しても、どちらの発言か分かります。発話動詞（言った／反論した）も使っていません。

### 例3：場の描写

❌ **AI くさい書き方**
> 　そこは美しく神秘的な森だった。木々の葉のあいだから陽光が差し込み、斑模様の影を落としている。空気には清々しい香りが満ちていて、心が洗われるようだった。

✅ **人が書いた文**
> 　林の中は暗かった。足元の落ち葉が踏むたびに軋む。腐った葉に松脂が混じった匂いがして、嫌な匂いではないが、少し重い。頭上の隙間から光が漏れて、地面にいくつも明るい輪を描いている。虫がその輪のまわりを飛んでいた。

**どこが違うか**：後者には聴覚（軋む）、嗅覚（腐葉と松脂）、視覚（光の輪、虫）があり、触覚に近い感覚（重い）も入っています。「美しい」「神秘的」「清々しい」のような形容詞に頼っていません。

### 例4：文末のリズム

❌ **同じ文末が続いている**
> 　森田は立ち上がった。窓の外を見た。雨が降っていた。傘を持ってこなかったことを思い出した。ため息をついた。

✅ **文末を混ぜている**
> 　森田は立ち上がり、窓の外を見た。雨。傘は家に置いてきている。
> 　ため息が出た。

**どこが違うか**：前者は「〜た。」が五回続いています。後者は体言止め（雨）、現在形（置いてきている）、短い段落を混ぜています。読むときの息が変わります。

</writing-examples>

## 章の書き出し 五つの型

<chapter-openings>

> 書き出しに迷ったら、この五つから選んでください。

### 1. 動きから入る — すぐ場面に入れる

```
　[人物]が[具体的な動作]をしている。そこへ[予想外のこと]が起きる。
```

**例**
> 　森田の指が出席簿の上で止まった。書き損じたのではない。机が揺れている。はじめは微かに、それから壁がぱらぱらと埃を落としはじめた。

**向いている章**：すぐ読者を掴みたい章（事件の直前、転換点）

### 2. 会話から入る — 関係がすぐ分かる

```
「[引きのある、あるいは対立を含む一言]」
　[人物]が[動作]。
```

**例**
> 　「三回助けた借りは、いつ返してもらえるんですか」
> 　杉本は戸口にもたれて、手の中の草の茎をいじっていた。今日の天気を訊くような調子だった。

**向いている章**：二人のあいだに張りがある章、関係を見せたい章

### 3. 場の描写から入る — 空気を作る

```
　[音／匂い／温度などの感覚]の描写。[人物の動作か受け止め]。
```

**例**
> 　雨は三日降って、やむ気配がない。路地の水は踝まで来ていて、泥と何か分からないものが混じっている。一歩ごとに生ぐさい匂いが立つ。森田は書類を頭の上に掲げ、爪先で水を探りながら進んだ。

**向いている章**：空気を作りたい章、場所が変わる章

### 4. 回想から入る — 過去から入る

```
　[人物]が[過去の光景]を思い出す。[いまとのつながり]。
```

**例**
> 　柳井が森田に初めて会ったとき、森田は七つで、教室の戸口にうずくまって授業を盗み聞きしていた。その子どもがいま、目の前に立っている。手にあってはならないものを持って。

**向いている章**：人物の背景を明かす章、過去と現在をつなぐ章

### 5. 謎から入る — 問いを先に出す

```
　[異常な出来事か一言か結果]。[人物]が知らないのは[より重要なこと]。
```

**例**
> 　貼り出した掲示は半日で剥がされた。森田が知らないのは、剥がしたのが字を嫌った誰かではなく、その墨に何が混ざっているかを見抜いた者だということだ。

**向いている章**：好奇心を作りたい章、読者を引っ張りたい章

</chapter-openings>

## よくある困りごと

<beginner-faq>

**Q: どこから書き始めればいいか分からない**
→ いちばん書きたい場面から書いてください。第1章から書く必要はありません。書きたい場面を書いてから、前を埋めます。

**Q: 会話が自然にならない**
→ 声に出して読んでください。読みにくいところ、言いにくいところが直すべきところです。「人はこう話すか」と自分に訊きます。

**Q: 場の描写が空っぽに感じる**
→ その場所に立っているつもりになって、見えるもの、聞こえるもの、匂うもの、肌に感じるものを順に挙げてください。感じたものを書けば埋まります。

**Q: 書いていてプロットから外れた**
→ 少し外れるのは問題ありません。大きく外れたら手を止めて、「この新しい方向はプロットよりよいか」を考えます。よければプロットを直します。よくなければ戻します。

**Q: 1章はどれくらいの長さがよいか**
→ 3,000〜6,000文字が読みやすい範囲です。短すぎると場面が立たず、長すぎると読者が疲れます。山場の章は8,000文字まで伸ばしてかまいません。

**Q: 書いているうちに人物がぶれる**
→ 一人につき口癖と話し方の癖を1つ決めてください。書くときに「この人はこれをどう言うか」と心の中で唱えます。迷ったら人物の設定を読み返します。

**Q: 章の終わりがうまく決まらない**
→ 三つの手があります。① 引き（「戸を開けて、立ち止まった」）② 急転（思わぬ人物が現れる）③ 問い（人物が選べない状態に置かれる）。どれか一つを使って、平らに終わらせないでください。

**Q: 書いたものが AI の文に見える**
→ 次の語を検索してください。「思わず」「胸が熱くなった」「その瞬間」「まるで」「世界が」。見つかったら動作と細部に書き換えます。あわせて文末が「〜た。」で三回以上続いていないか確かめてください。

**Q: 三人称一元視点がよく分からない**
→ 「彼は」「彼女は」で語りますが、一つの場面では一人の心の中だけを書きます。その人が見ていないこと、知らないことは書きません。場面が変わるまで、カメラをその人の肩に固定する感覚です。

</beginner-faq>

## 五感の使いかた

<sensory-guide>

### 場面ごとの選びかた

| 場面 | 主に使う感覚 | 補う感覚 |
|---|---|---|
| 争い・追跡 | 視覚＋触覚 | 聴覚 |
| ふだんの会話 | 聴覚 | 視覚 |
| 食事・宴 | 味覚＋嗅覚 | 視覚 |
| 怖い場面・謎 | 聴覚＋触覚 | 嗅覚 |
| 回想・思慕 | 視覚＋触覚 | 嗅覚（記憶を最も強く呼ぶ） |
| 自然の中 | 視覚＋嗅覚 | 聴覚 |

### 要の場面は重ねる

次の場面では少なくとも3種を使います。
- 人物が初めてその場所に入るとき
- 山場・転換点
- 感情がもっとも強く動くとき

### ふだんの場面は抑える

場面をつなぐだけの箇所は1〜2種にとどめます。書き込みすぎると読者が疲れます。

</sensory-guide>

## シーンの2種類

<scene-types>

### 行動シーン（Goal → Conflict → Disaster）

```
目的: 人物が手に入れたいもの（はっきりと、具体的に）
  ↓
障害: 何が立ちふさがるか（相手、状況、自分自身）
  ↓
つまずき: 思っていたより悪くなる（ただ失敗するのではなく、事態が複雑になる）
```

**押さえどころ**
- 目的はシーンの前半三分の一までに示す
- 障害は一方的でなく、やり取りがある
- つまずきは新しい問題を生み、話を先へ押す

### 反応シーン（Reaction → Dilemma → Decision）

```
受け止め: 前のシーンへの感情の反応（理屈ではなく)
  ↓
板挟み: どちらを選んでも代償がある
  ↓
決断: 決めて、次の行動シーンへつなぐ
```

**押さえどころ**
- 受け止めは感情のもので、乱れていても矛盾していてもよい
- 板挟みは本当に難しくする。正解が明らかなら板挟みではない
- 決断には代償を払わせ、次の伏線にする

### 交互に置く

```
行動（張る） → 反応（受け止める） → 行動（より張る） → 反応（より深く受け止める） → …
```

行動シーンが2〜3続いたら反応シーンを挟み、人物と読者の両方に息継ぎをさせます。

</scene-types>

## 前章とのつなぎ

<continuation>

### 第2章以降の決まり

1. **書き出しを重ねない** — この章の書き出しが前章の末尾と重なっていないか確かめる
2. **自然につなぐ** — 前のシーンの終わりから続ける
3. **話を進める** — プロットが指す新しい出来事まで到達する
4. **前章の末尾を読む** — `novel_context` が前章の末尾を渡します。分量は `.novel/config.json` の `limits.previousChapterTail` で変えられます（既定 1,200文字）

### 長編でぶれないために

- 5章ごとに一度、つじつまを確かめる
- 人物の話し方の癖を保つ（口癖、語尾）
- 時間に矛盾を作らない（昼夜の移り、季節の進み）
- 持ち物と能力を突然現したり消したりしない
- 表記規約（会話の「」、`……`、`――`、感嘆符のあとの全角スペース、段落頭の字下げ）を全章で揃える

</continuation>
