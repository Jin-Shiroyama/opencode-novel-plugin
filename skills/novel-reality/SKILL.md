# 现实映射创作指南

本 Skill 帮助作者从真实世界中发现创作素材，将社会现实融入小说。核心思路：不是照搬现实，而是通过"陌生化"处理，让读者在虚构世界中感受到真实的重量。

---

## 一、批判现实主义创作方法论

基于周志强等学者的理论，用大白话解释三种现实主义形态，帮你选对创作路径。

### 1. 典型现实主义——写"人物的故事"

塑造典型人物，通过个人命运反映时代。

**核心操作**：创造一个"所有人都认识但没有人真的是"的角色。比如阿Q、祥林嫂、林黛玉——每个人身上都有这些角色的影子，但没有一个真人和他们完全一样。

**适合**：严肃文学、历史小说、想拿文学奖的作品。

**关键技巧**：
- 从100个真人身上各取一个特征，合成一个角色
- 个人的困境必须映射一个时代的困境
- 角色的命运要有"必然性"——读者觉得"只能这样"

### 2. 抽离现实主义——写"人化的故事"

将人抽象为理念载体，用符号化表达。

**核心操作**：角色不再是"一个人"，而是"一种人"。卡夫卡的《变形记》里格里高尔变成甲虫——没有人真的变成甲虫，但所有人都理解那种被异化的感觉。

**适合**：寓言体、讽刺小说、实验性作品。

**关键技巧**：
- 找到一个核心隐喻（变成甲虫、看不见的墙、永远到不了的城堡）
- 所有细节都围绕隐喻展开
- 读者看完后会沉默，而不是感动

### 3. 游戏现实主义——写"人们的故事"

基于个体肉身经验，不追求宏大叙事。

**核心操作**：写具体的人在具体的处境下做出的具体选择。不追求"反映时代"，只追求"这一刻是真的"。网文中那些让读者说"这太真实了"的桥段，往往就是这个层次。

**适合**：网络小说、类型小说、日常向作品。

**关键技巧**：
- 细节越具体越真实（不是"他很穷"，而是"他盯着超市打折标签算了一小时"）
- 不评判角色，只呈现选择
- 让读者自己得出结论

### 核心原则（大白话版）

1. **不是简单"反映"现实，而是找到"通向真实的途径"**。照片和油画都能展现一个人，但方式完全不同。你要做的是油画。

2. **不只描述现象，要追问"为什么"**。写出"一个打工人挤地铁"不难，写出"为什么他每天挤两小时地铁还要笑着说没事"才见功力。

3. **让读者自己得出结论，不要说教**。最好的社会批判不是"你看这个社会多不公平"，而是让读者看完后自己说"这也太不公平了"。

## 二、陌生化技法库

陌生化 = 把熟悉的东西变得陌生，让读者重新"看见"。俄国形式主义的核心概念，但这里只讲实用技巧。

### 1. 视角转换

**一句话**：换一个不可能的视角讲故事。

**适用场景**：习以为常的社会现象需要重新审视时。

**示例**：用送外卖的骑手视角写城市，用儿童视角写职场斗争，用动物视角写人类战争。

**武侠应用**：用一个扫地老仆的视角写武林大会——在他看来，一群人为了一块破牌子打得头破血流，而他每天扫掉的头发比在场所有人的加起来都多。

### 2. 时间变形

**一句话**：打乱时间线，从结局开始或同时呈现多个时间。

**适用场景**：想强调命运的必然性或历史的重复时。

**示例**：先写葬礼再写人生，或在同一段里交替写少年和老年。

**武侠应用**：开场就是一代宗师的死，然后倒叙他如何从街头混混一步步走到巅峰。读者从第一页就知道他会死，所以每个选择都带着宿命感。

### 3. 空间转换

**一句话**：把熟悉的场景搬到异域/古代/未来。

**适用场景**：现实题材过于敏感或想营造距离感时。

**示例**：把办公室政治写成宫廷斗争，把校园霸凌写成荒岛求生。

**武侠应用**：把职场内卷写成门派内斗——"内门弟子名额只有三个，但报名的有三十个，而且其中六个是长老的孩子"。

### 4. 语言陌生化

**一句话**：用方言/古语/自造词打破日常语言惯性。

**适用场景**：想让读者"慢下来"认真读每一个字时。

**示例**：用文言文写现代职场，用网络用语写古代战争。

**武侠应用**：让一个从塞外来的角色说话永远是倒装句法，而且用词永远"不对"——他说"吃"为"进"，说"死"为"归"，说"爱"为"欠"。其他角色听他说话总觉得怪，但慢慢习惯了。等他走后，主角发现自己也在用他的方式说话。

### 5. 感官置换

**一句话**：用非视觉感官（触/嗅/听）描述日常场景。

**适用场景**：视觉描写过多导致画面感模糊时。

**示例**：用嗅觉描述一个城市（汽车尾气、路边烤红薯、下水道），用触觉描述一段关系（"她的手指冰凉，像冬天忘了关的窗户"）。

**武侠应用**：一场高手过招，完全不写画面，只写声音——"嗤"的一声是内力破空，"叮"的一声是兵刃相交，然后安静了。安静了三息。主角听到自己的心跳，比打斗时还快。

### 6. 尺度放大

**一句话**：把小事件放到极端环境考验。

**适用场景**：想测试人性的某个侧面时。

**示例**：一次让座放大为生死抉择，一句闲话放大为引发战争的外交事件。

**武侠应用**：两个侠客在客栈争一个馒头——不是因为饿，而是因为对方先看了一眼自己的剑。这个馒头成了面子、尊严和江湖地位的象征，最后十几条人命搭进去。事后所有人都不记得是怎么开始的。

### 7. 身份对调

**一句话**：让特权者和弱势者互换位置。

**适用场景**：想揭示权力结构的荒谬性时。

**示例**：老板变成员工、老师变成学生、狱卒变成囚犯。

**武侠应用**：正派掌门被人用邪术变成了一只猫，被自己门派的弟子捡到。他亲眼看着弟子们在背后议论他、模仿他、嘲笑他，才知道自己在别人眼里是什么样。

### 8. 规则改变

**一句话**：改变世界的某条基本规则。

**适用场景**：想探讨"如果事情不是这样呢"时。

**示例**：说谎者身体会发光、杀人者会继承死者的记忆、每个人只能说出固定数量的字。

**武侠应用**：设定一个"因果境"——在这片区域内，你对别人做的事会立刻反弹到你身上。你打别人一拳，自己也会疼。你说好话，自己也会开心。所有正邪大战到了因果境内，都得重新想怎么打。

### 9. 文化错位

**一句话**：把一种文化的常识放到另一种文化中显得荒谬。

**适用场景**：想讽刺某种文化现象时。

**示例**：向原始部落解释"996"，向外星人解释"双十一"。

**武侠应用**：一个西域来的和尚不理解为什么中原武林要分"正"和"邪"——"你们的佛经里不是说万法归一吗？那武功为什么不能归一呢？谁规定的正？谁规定的邪？"中原侠客们被问得哑口无言。

### 10. 拼贴重组

**一句话**：将不相关的真实碎片拼接成新叙事。

**适用场景**：有多个零散的灵感素材但无法单独成篇时。

**示例**：把三则不相关的新闻拼成一个完整的故事。

**武侠应用**：把"外卖骑手闯红灯"、"老教授被学生举报"、"拆迁户一夜暴富"三条新闻的内核提取出来，拼成一个故事——一个送信的镖师为了赶时间走了邪道，被正派弟子举报，结果发现他送的信里记载着一处宝藏的线索，整个门派的人都疯了。

## 三、人物原型提取框架

从真实人物提取虚构角色的四步法。核心原则：提取的是"模式"和"结构"，不是具体的人。

### 步骤1：观察

记录一个人最外在的特征，不需要深入分析，只记录事实：

- **最常说的3句话**：一个人的口头禅暴露他的思维模式。"随便"说明回避冲突，"你应该"说明控制欲，"没事"说明不愿示弱。
- **身体习惯和口头禅**：说话前清嗓子、紧张时摸耳朵、思考时咬笔帽。这些小动作比任何形容词都更有辨识度。
- **对冲突的反应方式**：面对冲突，是先解释？先道歉？先反击？先沉默？这暴露一个人的生存策略。
- **压力下的表现**：平时温文尔雅的人压力大时是什么样？这是角色最真实的时刻。

### 步骤2：识别核心驱动力

透过外在行为看到内在动力：

- **主要恐惧**：怕被抛弃？怕被看不起？怕失去控制？怕平庸？恐惧是推动一切行为的底层引擎。
- **核心欲望**：真正想要什么？不是嘴上说的，是深夜辗转反侧时想的那件事。
- **内部矛盾**：恐惧和欲望如何打架？想被爱又怕被伤害，想自由又怕孤独，想成功又怕改变。
- **防御机制**：如何保护自己不面对恐惧？幽默、逃避、攻击、讨好、麻木——每个人有不同的盾牌。

### 步骤3：映射到原型

将提取的特征映射到经典原型（基于荣格原型理论，适配武侠创作）：

| 原型 | 核心特征 | 武侠角色示例 |
|------|---------|------------|
| **英雄** | 追求证明自己，战胜困难，成长蜕变 | 初出茅庐的少年侠客，为了证明自己而踏上江湖路 |
| **阴影** | 代表被压抑的一面，可能是反派也可能是主角的暗面 | 被正派驱逐的叛徒，他做的一切坏事都源于当年被冤枉 |
| **智者** | 拥有知识和经验，引导他人 | 隐居山间的老顽童，看似疯癫实则看透一切 |
| **叛逆者** | 挑战规则和权威，打破旧秩序 | 不服师门管教的女侠，自立门户创立新功法 |
| **守护者** | 保护他人，忠诚可靠 | 默默守护主角的师弟，从不说出口但永远挡在前面 |
| **创造者** | 追求创造和表达，有艺术气质 | 痴迷于铸造神兵的铁匠，为了一把剑可以耗尽一生 |
| **统治者** | 追求控制和权力，建立秩序 | 门派掌门，维持秩序但手段越来越极端 |
| **弄臣** | 用幽默和讽刺揭示真相 | 茶馆里说书的老头，每句话都在暗讽江湖乱象 |

### 步骤4：虚构化改造

6种安全模糊化技巧，确保不会被人对号入座：

1. **改名换姓**：这是最基本的。但不要只是改个同音字，要完全换一个风格的名字。
2. **外貌调整**：性别、身高、体型、年龄都可以改。一个矮胖的中年男人可以变成一个高瘦的年轻女子——保留的是性格内核。
3. **职业/身份重组**：把老师的特征给掌柜，把医生的口头禅给铁匠。职业变了但说话方式没变。
4. **时间线挪移**：把当代人的故事放到古代，或者反过来。十年前的事放到三个月前。
5. **地域转换**：把北方人的故事搬到南方，把城里人的习惯放到乡下。文化背景一变，整个故事的感觉都不同了。
6. **多人融合**：这是最推荐的方式——将三四个真人的特征合成一个角色。甲的口头禅、乙的恐惧、丙的外貌、丁的职业，谁都对不上号。

## 四、现实→虚构映射模板

提供一个系统化的映射方法，帮助你有章法地将现实素材转化为虚构元素。

### 映射维度表

| 维度 | 现实素材 | 虚构转化 | 武侠转化示例 |
|------|---------|---------|------------|
| **权力结构** | 官场/企业/体制 | 门派/帮会/朝廷 | 正邪门派斗争映射办公室政治 |
| **资源分配** | 财富/教育/医疗 | 功法/灵药/秘籍 | 修炼资源争夺映射社会资源不公 |
| **身份困境** | 户籍/阶层/族裔 | 出身/血统/门第 | 旁门左派弟子被歧视映射社会偏见 |
| **信息不对称** | 舆论操控/信息茧房 | 秘辛/阴谋/秘闻 | 江湖谣言映射网络舆论 |
| **代际冲突** | 传统vs现代 | 师徒/新旧武功 | 师门旧规映射传统束缚 |

### 映射检查清单

每次完成现实→虚构映射后，用这个清单自查：

- [ ] **陌生化检查**：现实素材是否经过"陌生化"处理，而非照搬？如果读者能一眼认出原型，说明陌生化不够。
- [ ] **共鸣检查**：读者能否在虚构世界中感受到现实的影子？如果完全感觉不到，说明映射太远了。
- [ ] **多维视角检查**：映射是否提供了多重视角（不是非黑即白）？好故事没有绝对的坏人。
- [ ] **隐私检查**：是否避免了直接对应真实人物？改名换姓是最基本的要求。
- [ ] **主题统一检查**：映射是否服务于故事的核心主题？不要为了映射而映射。

## 五、法律合规指南

创作自由有边界。以下是必须遵守的法律红线：

1. **不侮辱、不诽谤真实人物**：即使你很讨厌某个人，也不能在小说里写一个名字相似、外貌相似、经历相似的角色去干坏事。读者能对号入座就算侵权。

2. **不暴露真实人物隐私**：一个人的疾病、家庭矛盾、私生活细节——即使你亲眼所见，也不能直接写进小说。

3. **不用真实姓名+可识别特征组合**：改名但保留特征，或者改特征但保留名字——两者都做了才行。

4. **添加"本故事纯属虚构"声明**：这是法律保护的最低要求。在作品开头或结尾注明。

5. **灵感来自现实但必须经过充分艺术化处理**：法律上有个"合理使用"的概念。你从新闻中获得灵感是可以的，但如果读者能从你的描述中认出具体的新闻事件和当事人，就有法律风险。

**简单判断标准**：如果当事人看了你的小说，会觉得"这写的就是我"，那就危险了。如果当事人看了会觉得"好像有点像我，但又完全不是"，那就安全了。

## 六、新闻/历史素材搜索指南

指导 Agent 如何使用 websearch/webfetch 等工具获取现实素材。

### 搜索什么

- **社会热点**：引发广泛讨论的新闻事件。不是为了蹭热点，而是这些事件往往暴露了最深层的社会矛盾。
- **历史事件**：历史不会重复，但会押韵。很多古代故事和今天的社会现象惊人地相似。
- **人物故事**：普通人的不普通经历。外卖小哥救人、乡村教师坚守、老人被骗——每个人的故事背后都有值得书写的冲突。
- **争议话题**：两方甚至多方都有道理的争议最好写，因为天然就有戏剧性。

### 如何分析

1. **提取核心冲突**：不要关注具体细节，要找到事件的本质矛盾。不是"张三和李四吵架"，而是"资源有限时信任如何瓦解"。
2. **识别权力关系**：谁在支配？谁在被支配？为什么？这个"为什么"往往是最有价值的素材。
3. **挖掘人性层面**：事件中的人做了什么选择？为什么这么选？换了你你会怎么选？这三问能把任何新闻变成角色原型的素材。

### 如何转化

1. 用本 Skill 的"陌生化技法库"将素材转化为虚构元素。
2. 用"现实→虚构映射模板"确保映射的系统性和一致性。
3. 用"人物原型提取框架"从新闻人物中提取可用的角色原型。
4. 用"法律合规指南"确保转化后的素材安全可用。
