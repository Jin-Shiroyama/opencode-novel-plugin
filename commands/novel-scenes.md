<command-instruction>

あなたはシーン設計の手伝いをします。

## 前に確かめること

1. `novel_status(detailed: true)` で前の工程が済んでいるか確かめる
2. 章別プロットができていなければ `/novel-outline` を先に実行してもらう
3. シーン一覧ができていれば、作り直すか尋ねる

## 進めかた

### 一、skill を読み込む

`novel-workflow` skill を読み込み、シーン設計の手順を確かめます。

### 二、前提を読む

次を読みます。
- `.novel/outline-detailed.md` — 章別プロット
- `.novel/characters/profiles.md` — 登場人物
- `.novel/world-building.md` — 世界観

### 三、進め方を決める

`Question` ツール（あなたのプロンプトにある「シーン設計の工程」の型）で聞きます。

1. **シーンの密度** — 1章あたり 2〜3／3〜4／4〜5
2. **緩急** — きっちり交互／全体で釣り合えばよい／前は緩やかで後ろで加速
3. **進め方** — 章ごとに相談／まとめて作ってから確認／大事な章だけ相談

### 四、シーンを作る

選ばれた進め方に沿って、章ごとかまとめて作ります。各シーンに次を書きます。

1. **シーンID** — `章番号.連番`（1.1、1.2、2.1 のように）
2. **種別** — 行動シーン（目的→障害→つまずき）／反応シーン（受け止め→板挟み→決断）
3. **視点人物** — 1シーンに1人だけ
4. **三要素** — 種別に応じた中身
5. **想定文字数**
6. **_Prompt** — 執筆の手引き（Role / Task / Character / Emotion / Sensory / Pacing / Avoid / Restrictions / Success）

**シーンの見出しは「### 1.1 シーンタイトル」の形で書いてください。**
「### シーン1.1 …」「### Scene 1.1 - …」でも読み取れます。
状態は `- [ ] **状態**：未着手` の形で書くと、進捗が集計されます。

### 五、保存する

できたシーン一覧を Edit ツールで `.novel/scenes.md` に書き込みます。

### 六、確認して次へ案内する

```
✅ シーン一覧を作りました

🎬 決まったこと
• シーン総数：{N}
• 行動／反応の比率：{N} / {N}
• 対応した章：第1〜{N}章

次にやること
• /write-chapter 1 — 第1章を書きはじめる
• /novel-status    — 進行状況を見る
```

## 約束

- 穴埋めではなく選択肢で聞く
- すべての問いは `Question` ツールで出す
- 行動シーンと反応シーンを交互に置き、緩急を作る
- どのシーンにも `_Prompt`（執筆の手引き）を付ける
- 視点人物は1シーンに1人に固定する
- 日本語で答える
