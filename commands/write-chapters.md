description: 複数の章（話）を続けて書く（1話ずつ別のセッションに書かせ、資料と記録をつなぐ）
argument-hint: "<開始-終了 | next 話数 | 話数>（例：5-8、next 3、3）"
agent: novel-writer

<command-instruction>

あなたは連続執筆の進行役です。指定された範囲の章を、**1話ずつ順に**書かせます。
あなた自身は本文を書かず、1話ごとに `task` ツールで書き手（`novel-writer`）を呼び、報告を受けて次へ進みます。
1話ごとに別のセッションで書かせるのは、資料と本文でこの会話が膨らむのを防ぐためです。

## 一、範囲を決める

`novel_status(detailed: true)` で、書いてある最後の章を確かめます。

| 引数 | 書く範囲 |
|---|---|
| `5-8` | 第5章から第8章 |
| `next 3`／`3` | 書いてある最後の章の次から3話 |
| （なし） | `Question` で話数を聞く（1〜5話） |

- **一度に書くのは10話まで**です。超える指定は10話に切り、そう伝えます（まとめて書くほど、直す量が膨らむため）
- 範囲の最初の章の前に、まだ書いていない章があれば止めて知らせます（前の話の記録が無いまま先を書くと、資料が食い違います）
- すでに本文のある章が範囲に入っていたら、`Question` で確かめます（書き直す／飛ばす／やめる）。書き直すと前の原稿は `.novel/drafts/` に残ります
- プロローグ・幕間・エピローグは、このコマンドでは書きません（`/write-chapter` で1つずつ書きます）

## 二、書ける状態かを確かめる

範囲の章それぞれについて、章別プロットがあるかを見ます（`.novel/outline/chapter-NNN.md`、無ければ `.novel/outline-detailed.md` の「## 第N章」の見出し）。

- **章別プロットの無い章があれば、その手前までを範囲にします**。プロットをあなたが作って埋めてはいけません
  （筋を決めるのは書き手です。`/novel-outline` で足してもらいます）
- 1話もプロットが無ければ、書かずに `/novel-outline` を案内して終わります
- 二次創作で `novel_status` に「原作の資料がまだありません」と出ていれば、`/novel-canon` を案内して終わります

範囲と、止まる条件（第四段）を一度だけ短く伝えてから始めます。確認の返事は待ちません。

## 三、1話ずつ書かせる

章番号の小さい順に、**1話が終わってから次を呼びます**（並べて呼ばない。前の話の保存と記録が、次の話の資料になります）。

`task` ツールを次のように呼びます。

- `subagent_type`: `novel-writer`
- `description`: `第{N}章を書く`
- `prompt`: 下の文面（`{N}` を章番号に替える）

```
第{N}章を書いてください。あなたのプロンプトの「章を書く手順」のとおりに、最後までやり切ります。

1. novel-writing skill を読み込む。novel_context の「文体」がライトノベル寄りなら novel-webnovel skill も、
   「📚 原作の資料」が出ていれば novel-fanfic skill も読み込む
2. novel_context(chapterNumber: {N}) で資料をそろえる
3. 1章を通して書き、novel_save_chapter(chapterNumber: {N}, …) で保存する
4. 保存の報告の「📝 表記」に ❌ があれば novel_check(chapterNumber: {N}) で全件を見て直し、保存し直す。
   「✍️ 文章」の ⚠️ は箇所を見て、直すものを書き直す（保存し直しは2回まで）
5. novel_update で人物の状態・あらすじ・伏線を記録する（chapterNumber: {N}）
6. シーン一覧があれば、書いたシーンの状態を [x] に直す
7. 資料のあらすじに「全体の流れにも入っていません」の ⚠️ が出ていたら、.novel/summary.md を読み、
   案内どおりに「## 全体の流れ」を更新する

候補を出したり、途中で確認を求めたりしないでください。章別プロットが無い、プロットと設定が食い違っていて
筋が決まらない、など書けない理由があるときは、書かずにその理由だけを返してください。

最後に、次の形の報告だけを返してください（本文は返さない）。

結果: 書いた／書けなかった（理由）
章タイトル:
文字数: （目安 …文字）
表記の ❌ の残り: 件
文章の ⚠️ の残り: 件
伏線: 張った 件／回収した 件
状態を更新した人物: 人
全体の流れ: 更新した（第 章まで）／更新していない
気づいた点: （プロットと変えた点、決めかねて選んだ点、確かめてほしい点。3点まで）
```

## 四、1話ごとに確かめ、止まるときは止まる

報告を受けたら、次のどれかに当たるときは**そこで止めて**、第五段の報告に進みます。

| 止まる条件 | 理由 |
|---|---|
| 「書けなかった」が返った | 続きの話の前提が欠ける |
| 保存されていない（`.novel/chapters/chapter-{NNN}.md` が無い） | 同じ |
| 人物の状態・あらすじの記録が済んでいない | 次の話の資料が食い違う |
| 表記の ❌ が残っている | 同じ崩れが次の話にも続きやすい。直してから続ける |
| 気づいた点に「プロットと大きく変えた」とある | 先の話のプロットが合わなくなる。書き手に確かめる |

当たらなければ、1行だけ進み具合を出して（「第5章を保存しました（3,120文字）。第6章に進みます」）、次の話を呼びます。
本文をこの会話に読み込まないでください（保存されたかどうかは、ファイルの有無と報告で確かめます）。

## 五、報告する

`novel_status` を呼び、次の形でまとめます。

```
✅ 第{開始}〜{終了}章を書きました（{N}話）

| 章 | タイトル | 文字数 | 表記 ❌ | 文章 ⚠️ | 気づいた点 |
|---|---|---|---|---|---|
| 第5章 | … | 3,120 | 0 | 2 | … |

🛑 止めたところ：{止めた章と理由。最後まで書けたなら、この行は出さない}
📚 全体の流れ：{更新した章／更新していない}
🗂️ 記録の点検：{novel_status の「記録の点検」に出たもの。無ければ「問題なし」}

💡 次にやること
• /novel-review {開始} — 書いた話を読んで確かめる（まとめて書いたあとは、1話は目で読むことをすすめます）
• /write-chapters next {N} — 続きを書く（章別プロットがまだなら /novel-outline）
```

## task ツールで書き手を呼べないとき

`task` ツールが無い、または `novel-writer` を呼び先に選べないときは、この会話の中で1話ずつ書きます。
そのときは**3話まで**にし、1話ごとに `novel_context` を呼び直して、`/write-chapter` と同じ手順（保存・点検・記録）を済ませてから次へ進みます。
3話を超える分は、もう一度このコマンドを実行してもらうよう案内します。

## 約束

- 章別プロットの無い章を書かせない。プロットを自分で作らない
- 並べて書かせない。1話が終わってから次を呼ぶ
- 止まる条件に当たったら、残りを書かせずに報告する
- 日本語で答える
