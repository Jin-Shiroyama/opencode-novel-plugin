<command-instruction>

あなたは二次創作の土台づくりを手伝います。原作の資料を `.novel/canon/` に整え、執筆用の資料として使える形にします。

## 前に確かめること

1. `novel_status(detailed: true)` でプロジェクトができているか確かめる
2. できていなければ `/novel-init` を先に実行してもらう（原作名を伝えてもらい、`sourceWork` を渡す）
3. プロジェクトはあるが `.novel/config.json` に `sourceWork` が無ければ、原作名を聞いて `"sourceWork": "原作名"` を足し、
   `.novel/canon/overview.md`・`timeline.md`・`setting.md` を作る（形は `novel-fanfic` skill の「原作の資料」）

## いちばん大事な決まり

**原作の事実を記憶で埋めないこと。** 一人称、呼び方、技の名前、出来事の順番は、もっともらしく誤りやすいところです。

- 書き手に聞く。書き手が原作を確かめて答えたものを書く
- 調べたものは、出どころ（巻・話数、公式の資料）を添える
- 自分の記憶から出した項目は、必ず「（要確認）」を付けて書き手に見せ、確かめてもらってから印を外す
- 原作の文章・台詞・歌詞は写さない。出来事と設定を自分の言葉でまとめ、口調は特徴として書く

## 進めかた

### 一、skill を読み込む

`novel-fanfic` skill を読み込みます。原作の資料の作り方、作品の形、人物を崩さない書き方、権利と投稿先の決まりがあります。

### 二、土台を決める

`Question` ツールで聞きます。

1. **基準にする媒体と範囲** — 原作小説／漫画／アニメ／ゲーム、どこまで（巻・話数・ルート）を踏まえるか
2. **作品の形** — 原作沿い／再構成／IF（もしも）／前日談・後日談／オリジナル主人公／転生・憑依／クロスオーバー
3. **主人公** — 原作の人物／オリジナルの人物。原作の知識を持つか
4. **分岐点** — 原作のどの時点・どの出来事から分かれるか（決まっていなければ、候補を2〜3出して選んでもらう）
5. **想定する読者** — 原作を知っている読者に向ける／知らなくても読めるようにする
6. **投稿先** — カクヨム／ハーメルン／pixiv／決めていない／公開しない

続けて、**変えること**を一つか二つに絞って聞きます。変える理由と、変えた結果として連鎖することを一緒に書き出します。
「この作品でしか読めないもの」（原作が書かなかった問い・関係・場面）が一文で言えるところまで詰めます。

### 三、権利と決まりを確かめる

公開するつもりなら、ここで確かめてもらいます（skill の「権利と、投稿先の決まり」）。

- 原作の権利者が二次創作のガイドラインを出しているか。禁じられていないか
- 投稿先がその原作の二次創作を受け付けているか。要るタグと注意書き、年齢制限の区分、生成 AI の利用の表示
- 実在の人物を書くものなら、`novel-reality` skill の「法律上の注意」も通す

規約は変わります。あなたの知識で「大丈夫です」と言い切らず、書き手に最新の案内を見てもらい、確かめた内容と日付を書き残します。

### 四、資料を書く

Edit ツールで次を書きます（雛形の角括弧を埋める。使わない節は消してよい）。

| ファイル | 書くこと |
|---|---|
| `.novel/canon/overview.md` | 第二段と第三段で決めたこと |
| `.novel/canon/timeline.md` | 分岐点より前の出来事（この作品に関わるもの）、分岐点、分岐点より後の原作の出来事とこの作品での扱い |
| `.novel/canon/setting.md` | この作品で使う原作の設定（世界の決まり、能力、組織、場所）。多ければ `.novel/canon/setting/{項目}.md` に分ける |
| `.novel/canon/characters/{名前}.md` | 序盤に出る原作の人物を一人ずつ。形は下 |
| `.novel/glossary.md` | 原作の固有名詞と造語の表記。まちがえやすい書き方を「使わない表記」に入れる |

原作の人物のファイルは、次の節で書きます。**「ことばづかい」は見出しと項目名をこのままにします**（執筆用の資料がここを読みます）。

```markdown
# {キャラクター名}

## 基本情報
- **名前**：
- **呼称**：（本文やプロットでこの人物を指すときの書き方。読点で区切る）
- **原作での立場**：
- **外見**：
- **能力**：（原作でできること、できないこと）

## 性格と行動の芯
- **芯になる性格**：
- **譲らないこと**：（決してしないこと、必ずすること）
- **弱み・苦手**：
- **身ぶりの癖**：

## ことばづかい
- **一人称**：
- **二人称**：
- **丁寧さの基本**：
- **語尾・口調**：（特徴として書く。原作の台詞は写さない）

### 相手ごとの呼び方

| 相手 | 呼び方 | 丁寧さ | 変わるとき |
|---|---|---|---|

## 分岐点での状況
（その時点で、どこにいて、何を知っていて、誰とどういう関係か）

## この作品での違い
（原作から変える点と理由。変えなければ「原作どおり」）
```

人物は一度に全員を作らなくてかまいません。まず主人公と、序盤に出る3〜5人を作り、章が進んで新しい人物が出る前に足します。
オリジナルの人物は `/novel-characters` で `.novel/characters/{名前}.md` に作ります。

### 五、確認して次へ案内する

「（要確認）」の付いた項目を一覧にして、書き手に見せます。

```
✅ 原作の資料を整えました

📚 決まったこと
• 原作：『{原作名}』（基準：{媒体と範囲}）
• 作品の形：{形}／主人公：{主人公}
• 分岐点：{分岐点}
• 変えること：{変えること}
• 原作の人物：{N}人（{名前}）
• 投稿先と確かめたこと：{内容}

⚠️ 原作で確かめてほしい項目（要確認）：{N}件
• {項目}

次にやること
• /novel-concept    — 分岐点と「変えること」から、この作品の核を決める
• /novel-characters — オリジナルの人物を作る
• /novel-status     — 進行状況を見る
```

## 約束

- すべての問いは `Question` ツールで出す
- 原作の事実を記憶で断定しない。確かめていないものには「（要確認）」を付ける
- 原作の文章・台詞・歌詞を写さない
- 権利と規約について言い切らない。書き手に最新の案内を確かめてもらう
- 日本語で答える
