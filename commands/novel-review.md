<command-instruction>

あなたは原稿を点検する役です。指定された章を見ます。

## 引数

| 引数 | 意味 |
|---|---|
| 章番号 | その章だけを見る（例：5） |
| `all` | 書き終わったすべての章を見る |
| `--focus=consistency` | つじつまだけを見る |
| `--focus=style` | 文章だけを見る |
| `--focus=pace` | 緩急だけを見る |
| `--focus=typography` | 表記だけを見る |
| `--focus=full` | すべて見る（既定） |

## 進めかた

<review-flow>

### 一、skill を読み込む

`novel-editor` skill を読み込み、点検の手順と結果の形を確かめます。
表記規約と AI くさい言い回しの一覧は `novel-writing` skill が正本なので、
表記と文章を見るときはあわせて読み込みます。

### 二、突き合わせる資料を読む

次を読みます。
- `.novel/config.json` — 作品設定
- `.novel/characters/profiles.md` — 登場人物
- `.novel/characters/state.json` — 人物の現在の状態
- `.novel/world-building.md` — 世界の約束ごと
- `.novel/summary.md` — これまでのあらすじ
- `.novel/foreshadow.json` — 伏線
- 対象の章のファイル — 本文

### 三、点検する

`--focus` に応じて見ます。

#### consistency（つじつま）
- 人物の言動が設定どおりか
- 世界の約束ごとを破っていないか
- 時間に矛盾がないか（出来事の順序、昼夜、季節）
- 持ち物と能力が突然現れたり消えたりしていないか
- 視点人物が1シーンに1人に保たれているか
- 伏線が計画どおりに扱われているか

#### style（文章）
- AI くさい言い回しがないか（`novel-writing` skill の A〜E 群で確認）
- 「見せる、語らない」ができているか
- 台詞が人の喋り方になっているか
- 比喩が多すぎないか（1,000文字に1つまで）
- 文末が単調でないか（「〜た。」が3文以上続いていないか）

#### pace（緩急）
- 行動シーンと反応シーンの比率
- 張る場面とゆるむ場面が交互にあるか
- 章の書き出しが読者を掴んでいるか
- 章末に引きがあるか
- 情報の詰まり具合

#### typography（表記）
- 会話の「」と、会話文末の句点の有無
- 三点リーダ「……」とダッシュ「――」（2つ重ね、偶数個）
- 感嘆符・疑問符が全角か、直後の全角スペースが規約どおりか
- 段落頭の字下げ（会話行は字下げしない）
- 漢数字と算用数字の混在

#### full
上のすべて。

### 四、結果を出す

`novel-editor` skill の「点検結果の雛形」の形で出します。
**よく書けていたところを必ず含めてください。**

### 五、直し方を示す

見つけたことには必ず次を添えます。
1. 何が起きているか（段落か文を特定する）
2. なぜ問題か（読者の読み心地にどう響くか）
3. 直す前と直した後の具体例
4. 書き手が同意すれば、直した本文

</review-flow>
