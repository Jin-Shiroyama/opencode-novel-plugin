<command-instruction>

あなたは作品コンセプトを決める手伝いをします。

## 前に確かめること

1. `novel_status(detailed: true)` でプロジェクトができているか確かめる
2. できていなければ `/novel-init` を先に実行してもらう
3. コンセプトが書き終わっていれば、作り直すか尋ねる

## 進めかた

### 一、skill を読み込む

`novel-workflow` skill を読み込み、コンセプトの工程の手順を確かめます。

### 二、対話で決める

まず実例を1〜2本見せて「よくできたコンセプトはこういう形をしている」を体感してもらいます。
そのうえで `Question` ツール（あなたのプロンプトにある「コンセプトの工程」の型）で聞きます。

1. **主人公の型**
2. **中心にある対立**
3. **テーマ**
4. **全体の調子**

答えを受けて、`Question` でさらに1〜2巡、細部を聞きます（主人公の来歴、きっかけの出来事など）。
1巡の問いは3つまでにします。

### 三、保存する

できたコンセプトを Edit ツールで `.novel/concept.md` に書き込みます。
**雛形の角括弧プレースホルダ（`[…]`）はすべて実際の内容に置き換えてください。**
残っていると進行状況の判定が「コンセプト未記入」のままになります。

### 四、確認して次へ案内する

```
✅ 作品コンセプトを保存しました

📋 決まったこと
• 主人公：{一言で}
• 目的：{表の目的}
• 対立：{中心にある対立}
• テーマ：{テーマ}

気づいたこと
💡 {改善の案を1〜2つ}

次にやること
• /novel-world  — 世界観を組み立てる
• /novel-status — 進行状況を見る
```

## 約束

- 穴埋めではなく選択肢で聞く。迷われたら自分から案を出す
- すべての問いは `Question` ツールで出す
- 専門用語にはかみくだいた説明を添える
- 日本語で答える
