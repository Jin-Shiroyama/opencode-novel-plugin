<command-instruction>

あなたはプロットを作る手伝いをします。

## 前に確かめること

1. `novel_status(detailed: true)` で前の工程が済んでいるか確かめる
2. 登場人物が未記入なら `/novel-characters` を先に実行してもらう
3. プロットができていれば、作り直すか尋ねる

## 進めかた

### 一、skill を読み込む

`novel-workflow` skill を読み込み、プロットの工程の手順を確かめます。

### 二、前提を読む

次を読みます。
- `.novel/concept.md` — 作品コンセプト
- `.novel/world-building.md` — 世界観
- `.novel/characters/profiles.md` — 登場人物

### 三、プロット概要を作る

まず三幕構成の実例を1〜2本見せます。そのうえで `Question` ツール（あなたのプロンプトにある「プロットの工程」の型）で骨の節目を聞きます。

1. **起点** — どんな状態から始まるか
2. **きっかけの出来事** — 日常を壊すもの
3. **中盤の転換** — 話の向きが変わる場面

答えを受けて、`Question` で山場と結末の方向を聞きます。
できたら Edit ツールで `.novel/outline-brief.md` に書き込みます。
三幕構成と起承転結の対応を書き添えてください。

### 四、プロット概要を確認してもらう

骨に納得してもらってから、章別プロットへ進みます。

### 五、章別プロットを作る

プロット概要をもとに章ごとに展開します。各章に次を書きます。

1. この章の出来事（1〜2文、または200〜300文字）
2. 登場する人物と状態の変化
3. 転換点
4. 感情の基調
5. 伏線の扱い（張る／補強／回収）
6. 章末の引き

できたら Edit ツールで `.novel/outline-detailed.md` に書き込みます。

**章の見出しは「## 第N章：タイトル」の形で書いてください。**
N は算用数字・漢数字のどちらでも読み取れますが、算用数字を推奨します。
この形で書かれていないと、`novel_context` がその章のプロットを取り出せません。

### 六、確認して次へ案内する

```
✅ プロットを作りました

📖 決まったこと
• 章数：全{N}章
• 目標文字数：{N}文字
• 三幕の比率：{N}% / {N}% / {N}%
• 転換点：{一覧}
• 2つのジレンマ：第{N}章／第{N}章

次にやること
• /novel-scenes — 各章をシーンに割る
• /novel-status — 進行状況を見る
```

## 約束

- 穴埋めではなく選択肢で聞く
- すべての問いは `Question` ツールで出す
- プロット概要と章別プロットを二段に分け、それぞれ保存後に確認を取る
- 2つのジレンマを必ず置く（どちらを選んでも失うものがある場面です）
- 日本語で答える
