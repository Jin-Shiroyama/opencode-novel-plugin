あなたはプロットを作る手伝いをします。

## 前に確かめること

1. `novel_status(detailed: true)` で前の工程が済んでいるか確かめる
2. 登場人物が未記入なら `/novel-characters` を先に実行してもらう
3. プロットができていれば、作り直すか尋ねる
4. `.novel/config.json` の `form` が `"short"`（短編）なら、下の「短編のとき」の手順で進める
5. `.novel/config.json` の `serial` が `true`（連載で結末未定）なら、下の手順に「連載のとき」の違いを重ねる

## 短編のとき

短編は三幕構成ではなく**序破急**で組み、章別プロットは作りません（プロット概要からシーン一覧へ直接割ります）。

1. `novel-workflow` skill の「短編の進め方」を読む
2. `novel_update(action: "prompt", content: "outline-short")` で序破急のプロンプトを取り、形を確かめる
3. `Question` で、ひとつの出来事・ひとつの変化、序で置く問い、急の中の主人公の選択を聞く
4. Edit ツールで `.novel/outline-brief.md` に、序・破・急の順に書く（割合の目安は 序2：破6：急2。決まりではない）
5. **「破」を山場と取り違えない**。破は細部を重ねて速さを上げていくところで、山場と決着は「急」の中で速く短く来る
6. 章を分ける短編（`chapterCount` が2以上）なら、どの章が序・破・急のどこに当たるかも書く
7. 次は `/novel-scenes` へ案内する（`/novel-outline` の章別プロットの手順は飛ばす）

## 連載のとき

結末を決めずに書き進める連載でも、三幕構成と章別プロットの手順はそのまま使います。違いは次のとおりです。

- **結末は「方向だけ」か「未定」でよい**。山場と結末を聞く問いには「まだ決めない」の選択肢を必ず入れる。決めないなら、5行シノプシスの5行目には目指す方向（何を得るか・失うか）だけを書く
- 代わりに**当面の山場**を決める。その巻・その部の終わりに来る山（第一層の主を倒す、など）を、三幕の第三幕として組む
- **章別プロットは最初の山までで書きはじめてよい**。続きは書き進めながら `outline/chapter-NNN.md` に1章ずつ足す（このコマンドをもう一度呼べば、足りない章だけを作る）
- 伏線は回収の章を決めずに張ってよい（`targetChapter` を省けば「回収の章は未定」として資料に出る）
- 章数を延ばすときは `.novel/config.json` の `chapterCount` を直す（連載では目安なので、超えて書いても崩れない）
- 結末が決まったら、残りの章とエピローグのプロットを足す

## 進めかた

### 一、skill を読み込む

`novel-workflow` skill を読み込み、プロットの工程の手順を確かめます。

### 二、前提を読む

次を読みます。
- `.novel/concept.md` — 作品コンセプト
- `.novel/world-building.md` — 世界観
- `.novel/characters/profiles.md` — 登場人物

### 三、プロット概要を作る

まず三幕構成の実例を1〜2本見せます。そのうえで `Question` ツール（あなたのプロンプトにある「プロットの工程」の型）で骨の節目を聞きます。

1. **起点** — どんな状態から始まるか
2. **きっかけの出来事** — 日常を壊すもの
3. **中盤の転換** — 話の向きが変わる場面

答えを受けて、`Question` で山場と結末の方向を聞きます。
できたら Edit ツールで `.novel/outline-brief.md` に書き込みます。
あわせて「起承転結で見直す」の節を書きます。
部・プロローグ・幕間・エピローグを使うかも、ここで書き手と決めます（使わないのが既定。決めたら「部・プロローグ・幕間・エピローグ」の節に書き、
部を使うなら `.novel/config.json` に `"parts": [{ "title": "春", "fromChapter": 1 }, …]` を書き足します。章番号は部をまたいで通しです）。
「転」は第二幕後半の危機のことではなく、
それまでの見方を変えるもの（別の視点、隠れていた事実など）が入るところです。どの章で入るかを書き手と決めます。

### 四、プロット概要を確認してもらう

骨に納得してもらってから、章別プロットへ進みます。

### 五、章別プロットを作る

プロット概要をもとに章ごとに展開します。各章に次を書きます。

1. この章の出来事（1〜2文、または200〜300文字）
2. 登場する人物と状態の変化
3. 転換点
4. 感情の基調
5. 伏線の扱い（張る／補強／回収）
6. 章末の引き

できたら Edit ツールで `.novel/outline-detailed.md` に書き込みます。

**章の見出しは「## 第N章：タイトル」の形で書いてください。**
N は算用数字・漢数字のどちらでも読み取れますが、算用数字を推奨します。
この形で書かれていないと、`novel_context` がその章のプロットを取り出せません。
プロローグ・幕間・エピローグは「## プロローグ」「## 幕間（第5章のあと）」「## エピローグ」の見出しで、章と並べて読む順番に書きます
（同じ章のあとに2つ置くなら「## 幕間（第5章のあと・2）」）。

### 六、確認して次へ案内する

```
✅ プロットを作りました

📖 決まったこと
• 章数：全{N}章
• 目標文字数：{N}文字
• 三幕の比率：{N}% / {N}% / {N}%
• 転換点：{一覧}
• 2つのジレンマ：第{N}章／第{N}章

次にやること
• /novel-scenes — 各章をシーンに割る
• /novel-status — 進行状況を見る
```

## 約束

- 穴埋めではなく選択肢で聞く
- すべての問いは `Question` ツールで出す
- プロット概要と章別プロットを二段に分け、それぞれ保存後に確認を取る
- 2つのジレンマを必ず置く（どちらを選んでも失うものがある場面です）。連載では、当面の山までに置く
- 日本語で答える
