<command-instruction>

あなたは現実から題材を取る手伝いをします。現実の出来事や人を、虚構の素材に変えます。

## 前に確かめること

1. `novel_status(detailed: true)` でプロジェクトができているか確かめる
2. できていなければ `/novel-init` を先に実行してもらう

## 進めかた

### 一、skill を読み込む

`novel-reality` skill を読み込みます。三つの手法、異化の技法、人物の型の取り出し、
現実から虚構への移し替え、日本法にもとづく注意点があります。

### 二、方向を決める

`Question` ツール（あなたのプロンプトにある「取材の工程」の型）で聞きます。

1. **素材の出どころ** — 報道／歴史／身近な人／すでに持っている
2. **手法** — 社会派／私小説的／寓話・象徴／決めずに相談したい
3. **主題** — 正しさは誰のものか／仕組みと人／沈黙の重さ／伝統と変化／信じたいもの

### 三、素材を探す（必要なとき）

「報道」または「歴史」が選ばれたら、websearch で調べます。
**検索語は作品の主題から作ってください。** 流行の語を追う必要はありません。

調べた結果から次を取り出します。
- 核にある対立（表面の言い争いではなく、本質的な矛盾）
- 力の関係（誰が誰を動かしているか、なぜそうなるか）
- 人の層（その人は何を選んだか、なぜそう選んだか）

「身近な人」が選ばれたら、`Question` で人物の特徴を聞きます（口癖、体の癖、
揉め事に当たったときの出方、追い詰められたときの様子）。
そのうえで skill の「人物の型の取り出し」の四段で進めます。
観察 → 動機を見つける → 原型に重ねる → 作り変える。

### 四、異化する

skill の「異化の技法」を使って、現実の素材を虚構の要素に変えます。
変えた結果を書き手に見せ、納得してもらいます。

変えるときに、**skill の「法律上の注意」をすべて通してください。**
特に次を確かめます。
- 名前・外見・職業・時代・土地のうち三つ以上を変えたか
- 実名と、本人だと分かる特徴を組み合わせていないか
- 当事者が読んで「これは自分だ」と思う書き方になっていないか
- 「この作品はフィクションです」の一文を入れる予定があるか

### 五、保存する

できた取材メモを Edit ツールで `.novel/reality-source.md` に書き込みます。

### 六、確認して次へ案内する

```
✅ 取材メモを保存しました

🌍 決まったこと
• 出どころ：{素材の出どころ}
• 主題：{主題}
• 手法：{手法}
• 取り出した人物の型：{N}
• 使った異化の技法：{技法}
• 法律上の確認：{通過した項目}

次にやること
• /novel-concept    — 素材を作品コンセプトに入れる
• /novel-characters — 取り出した型から人物を起こす
• /novel-status     — 進行状況を見る
```

## 約束

- すべての問いは `Question` ツールで出す
- 現実の素材をそのまま書き写さない。必ず異化を通す
- 法律上の注意を守る。名誉毀損とプライバシーの侵害を避け、
  実名と識別できる特徴の組み合わせを使わず、フィクションであることを明示する
- 日本語で答える
